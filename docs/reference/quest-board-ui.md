# 🔍 레퍼런스 역설계: 의뢰 수락·여러 개 담기·번짐 화면

> 2026-10-27 저녁, 사용자 "10개 이상의 임무 수락/의뢰 디자인 레퍼런스를 바탕으로 공부해보자" + 번짐이 "그쪽으로 영향이 갈 거라는 시각적 디자인". 확인된 것과 화면 기억을 구분한다(기억은 "(기억)" — 구현 전에 플레이 영상으로 확인). 확인 출처: Windows Central·helldivers.wiki.gg(헬다이버즈 2 은하전쟁 지도), Wikipedia(팬데믹), Fextralife(몬스터 헌터 월드 현상금).

## 1. 여러 의뢰를 담는 법

**포켓몬 불가사의 던전(구조대·탐험대)** — 게시판 두 개(일반, 현상수배)에서 의뢰를 골라 "수주 목록"에 담는다(동시에 최대 8개). 수주한 의뢰는 게시판에서 표시가 바뀌고, 그 던전에 들어가면 해당 층에 목표가 각각 생긴다. 목록 화면에서 의뢰마다 "진행/보류"를 켰다 끈다. → 담기는 목록에 들어가는 행위, 실제 효과는 던전에서 층마다 드러남. 우리 합동 출동의 원형.
**몬스터 헌터 월드 현상금(바운티)** — 출발 전에 자원 센터에서 등록하는 부목표 목록. 일반·한정·긴급(Critical)으로 나뉘고, 한정 3개를 다 끝내면 추가 보상. → "등록 칸 수가 정해진 목록", 종류별 색.
**위쳐 3 게시판** — 마을 게시판에 종이 쪽지가 핀으로 박혀 있고, 읽으면 쪽지가 떼어지며 퀘스트가 된다(기억). → 종이 + 물리적 표시(떼어짐)가 곧 상태.
**페르소나 5 메멘토스 의뢰** — 스마트폰 앱 화면 목록, 의뢰마다 대상 이름과 "몇 구역"(층) 표시, 수락한 것은 체크(기억). → 의뢰마다 "어느 층"이 한 칸에 보임.
**데스티니 2 현상금** — 수락하면 인벤토리의 카드 격자로 들어가고 카드에 진행 막대(기억). 칸 수 제한이 곧 선택 압박.
**다키스트 던전 원정 선택** — 지역 지도에서 원정을 고르면 길이(짧음/중간/긺)와 목표가 아이콘으로, 다음 화면에서 보급품을 카트처럼 담고 "출정"(기억). → 출발 직전 한 장 요약.
**딥 락 갤럭틱 미션 터미널** — 행성 지도 위 미션 아이콘마다 길이·복잡도를 막대 2~3칸으로, 경고·이상현상은 작은 아이콘 줄로(기억). → 숫자 대신 막대와 아이콘.

## 2. 지도 위에 일이 뜨는 법

**페이데이 2 Crime.net** — 도시 지도에 계약이 핀으로 떴다가 시간이 지나면 사라진다. 핀마다 난이도(해골)·보수 표시, 누르면 계약 카드(기억). → 마감을 핀 둘레 원형 타이머로.
**인투 더 브리치 섬 지도** — 구역을 누르면 목표 아이콘 2~3개와 보상 아이콘만 뜬다. 글은 한 줄(기억).
**XCOM 2 지구본** — 미션이 지구본 위 아이콘으로, 브리핑 화면은 목표·보상·시간 제한·적의 "어둠의 계획" 경고를 한 장에(기억).
**배틀 브라더스 계약** — 마을 의뢰인 목록, 해골 개수 난이도, 수락 전 협상(기억).

## 3. 번짐(퍼짐)을 보이게 하는 법

**팬데믹(보드게임)** — 도시 48개가 선으로 이어진 지도. 감염 카드가 나오면 그 도시에 큐브 1개. 이미 큐브 3개인 도시에 또 놓아야 하면 **발병**: 연결된 도시마다 큐브 1개씩. 연결 도시도 3개면 연쇄 발병. 발병 8번이면 패배. → 퍼짐이 **확정 규칙**이라 플레이어가 "다음에 어디서 터질지"를 계산한다. 큐브 수가 곧 위험도 표시.
**헬다이버즈 2 은하전쟁** — 행성 사이 공급선(노란 화살표)이 어느 행성으로 진격할 수 있는지 보여 주고, 행성마다 해방 % 파란 막대. 적의 침공은 공급선 이웃에서만 일어나고, 거점이 떨어지면 그 너머가 줄어든다. 개발자도 "이해하기 어렵다"는 피드백을 받고 공급선을 지도에 그렸다. → 선과 방향이 그려지지 않으면 퍼짐은 안 읽힌다.
**플레이그 Inc.** — 국가별 감염 색이 번지고, 비행기·배 경로가 선으로 지나간다(기억). → 경로가 움직이며 보여야 "그쪽으로 간다"가 읽힘.

## 우리에게
- 의뢰서는 종이·클립보드 그대로(사용자). 담은 의뢰서에 "담음" 도장 하나로 상태를 말한다(위쳐·PMD). 담은 종이는 클립보드 뒤에 겹쳐 가장자리가 보인다.
- 그 밤에 무슨 일이 몇 층에 있는지는 문장 대신 노선도처럼: 층 = 역, 목표 = 역 아이콘, 귀환 지점 = 환승 표시(을지로 지하철 톤, 딥 락 막대 + 메멘토스 "몇 층").
- 지도 핀 둘레 마감 링(페이데이), 경고는 아이콘(딥 락).
- 번짐은 팬데믹식 확정 규칙 + 헬다이버즈식 방향 화살표: 넘치기 직전 동네에서 이웃으로 화살표, 이웃에 "+1" 토큰을 미리 그린다.
