# 🔍 레퍼런스 역설계: 포켓몬 불가사의 던전 (파랑/빨강 구조대 · 시간/어둠/하늘의 탐험대)

> 우리 게임(수임 → 던전 → 정산 → 동료 영입)과 뼈대가 가장 비슷한 게임. 무엇을 어떻게 만들었고, 무엇을 가져올지 정리.
> 출처: Wikipedia, Bulbapedia (2026-10 확인). 세부 수치는 게임 버전마다 다를 수 있음.

## 1. 한 판 구조 (던전)
| 요소 | 방식 |
|------|------|
| 진행 | 층(floor) 단위. 층마다 맵 **무작위 생성**, 계단 찾으면 다음 층. 마지막 층에 목표/보스 |
| 전투 | **격자(칸) 위 턴제.** 내가 한 칸 움직이거나 기술 1번 = 1턴, 그동안 적도 1번 행동. 버튼을 누르고 있으면 빠르게 연속 이동해서 체감은 "느린 액션" |
| 조작 | 리더 1마리만 직접 조작. 동료(최대 3)는 AI가 따라오며 싸움 |
| 기술 | 기술 4개 + 사용 횟수(PP). 기술 고르기 = 빌드 |
| 던전 안 성장 | 레벨업(경험치 유지), 줍는 아이템(열매, 구슬, 씨앗, 기술머신) |
| 긴장 장치 | 배고픔 게이지, 몬스터 하우스(방에 적 대량), 함정 |
| 탈출 | 탈출 구슬로 중간 귀환 가능 |
| 실패 | 리더(스토리 중엔 파트너도) 쓰러지면 던전에서 쫓겨나고 **소지금 전부 + 아이템 절반 이상 손실**. 경험치는 안 잃음 |

## 2. 마을(허브) 구조
- **걸어다니는 마을.** 메뉴가 아니라 상점·은행·창고·도장·카페가 전부 **NPC 가게**고, 걸어가서 말 걸면 창이 열림.
- **길드**: 아침 조회(구호 외치기) → 게시판에서 의뢰 고르기 → 던전 → 저녁 식사 → 잠. **하루 루틴이 컷신으로 반복**되며 생활감을 만듦.
- 게시판 2종: **일반 의뢰판**(구조, 배달, 호위) / **현상수배판**(악당 체포). 각 최대 8개, 동시에 최대 8개 수주.
- 의뢰 완료 → 보상(돈, 아이템) + **랭크 포인트** → 탐험대 랭크 상승 → 더 어려운 의뢰·지역 해금.

## 3. 동료 영입
- 쓰러뜨린 야생 포켓몬이 **확률로 "동료가 되고 싶어 한다"**. (빨강/파랑은 종류별 "친구 에리어"가 있어야 영입 가능)
- 스토리 동료(파트너)는 확정 영입.
- 출동 전 **팀 편성**(최대 4).

## 4. 왜 1인 개발 참고로 좋은가 (제작 비용 역설계)
| 비용을 줄인 방법 | 효과 |
|-----------------|------|
| 격자 + 턴제 | 히트박스·물리·타격감 조정이 거의 없음. AI는 "한 칸 다가가기 / 기술 쓰기" 수준 |
| 작은 스프라이트 + 적은 프레임 | 대기·걷기·공격·피격 몇 장으로 수백 종 표현 |
| 무작위 맵 | 맵을 손으로 거의 안 그림. 타일셋만 던전별로 바꿈 |
| 의뢰 자동 생성 | "○○ 던전 ○층에서 △△ 구조" 문장 틀 + 표 → 콘텐츠 무한 |
| 기술·아이템 = 데이터 | 효과 수백 개가 표 + 작은 함수 (우리 registry 구조와 같음) |
| 스토리는 대화창 + 초상화 | 컷신 비용 거의 0. 초상화에 감정 몇 개 |

## 5. 우리 게임으로 가져올 것 / 버릴 것
| 가져올 것 | 우리 버전 |
|----------|----------|
| 게시판 의뢰 + 자동 생성 | 경리가 관리하는 의뢰판 (일반 / 현상수배 괴이) |
| 랭크 포인트 → 해금 | 사무소 **평판 등급** → 의뢰·구역 해금 |
| 걸어다니는 허브, NPC = 가게 | 옥탑방 + 골목. 경리 = 의뢰, 뚱냥이 = 감정·암시장 |
| 하루 루틴 컷신 | 아침 만담 → 의뢰 → 출동 → 귀가 만담 |
| 확률 영입 + 스토리 영입 | 이미 결정 ([recruit.md](../design/3-growth/recruit.md)) |
| 실패 = 돈·아이템 손실, 경험치 유지 | 이미 비슷 ([run-result.md](../design/2-night/run-result.md)) |
| 탈출 구슬 | 공중전화 |

| 버릴 것 | 이유 |
|--------|------|
| 배고픔 게이지 | 15분짜리 한 판엔 불필요한 귀찮음 |
| 수백 종 수집 규모 | 1인 개발 범위 밖 |
