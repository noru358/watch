# 🔍 레퍼런스 역설계: 인디 게임 화면 (의뢰판·밤 HUD·대화창·타이틀)

> 화면 개편 시안의 근거. 리뷰·위키로 확인된 것과, 화면 기억으로 적은 것을 구분한다(기억은 "(기억)" 표시 — 구현 전에 플레이 영상으로 확인할 것).
> 출처(2026-10-26 확인): Noisy Pixel·Steam 토론(산나비), 뉴스토마토 산나비 리뷰, Mechanics of Magic "Design Details in Papers, Please", Kotaku "The Art of Hades", Darkest Dungeon Wiki.

## 대화창
- 산나비: 대화 장면이 액션 게임치고 길다(전체 10~15분 분량, 건너뛰기 가능). 스팀에선 의미 없는 짧은 잡담이 많다는 불만이 크다. 도트라 얼굴 확대가 어려워 감정은 과장된 몸동작·눈 반짝임으로, 큰 장면은 카메라를 크게 빼서 보여 준다. 대사는 캐릭터 곁에 뜨는 짧은 말풍선 위주(기억).
- 하데스: 화면 아래 대화 상자 + 옆에 큰 상반신 초상화(표정 여러 장), 이름표. 대사는 짧고 매번 바뀐다(관계 대사가 수천 줄). 초상화가 크니 도트 캐릭터가 작아도 감정이 전달된다(기억).
- 카타나 제로: 대사가 캐릭터 위에 뜨고, 단어마다 색·떨림으로 감정을 표시. 상대 말이 끝나기 전에 끼어드는 빨간 선택지가 있고 대답에 시간 제한(기억).
- 나이트 인 더 우즈: 만화 말풍선이 캐릭터 머리 위에, 글자가 단어 단위로 튀어나온다(기억).
- 우리에게: 2등신 도트라 얼굴이 작다 → 이야기 장면은 하데스식 큰 초상화 + 하단 상자, 사무소 잡담과 밤의 혼잣말은 산나비·나이트 인 더 우즈식 머리 위 말풍선. 산나비 불만에서 배울 것: 한 줄로 짧게, 전부 건너뛰기, 잡담은 반복 금지.

## 의뢰판(일 고르는 화면)
- 페이퍼스 플리즈: 책상이 곧 UI. 서류가 물건처럼 책상 위에 놓이고 공간이 좁아서 정리가 플레이가 된다. 라벨은 작게, 사람 정보는 크게 써서 반복하면 한눈에 읽힌다. 하루는 신문 한 면으로 시작한다(우리 경리 아침 보고와 같은 자리).
- 인투 더 브리치: 섬 지도 위 구역을 고르면 그 구역의 목표가 아이콘 몇 개와 보상 아이콘으로만 뜬다. 글은 한 줄(기억).
- 다키스트 던전: 원정 고르기 화면에서 지역 지도 + 의뢰 아이콘, 길이·난이도는 아이콘, 보상은 아이템 그림(기억).
- 우리에게: 의뢰를 "서류 한 장"으로. 지도에서 핀을 누르면 클립보드에 의뢰서가 꽂히고, 의뢰서엔 의뢰인 한 줄 + 아이콘 지표(목표·난이도·길이·보수)만. 동네 오염은 지도 색으로만.

## 밤 HUD
- 엔터 더 건전: 왼쪽 위에 하트·공포탄·열쇠·돈, 오른쪽 아래에 탄창. 화면 가운데는 비운다(기억).
- 하이퍼 라이트 드리프터: 왼쪽 위 체력 칸과 에너지 막대뿐, 글자 없음(기억).
- 데드 셀: 왼쪽 아래 체력 막대 + 무기·스킬 칸, 위쪽은 비움(기억).
- 하데스: 왼쪽 아래 체력·죽음 거부, 오른쪽 아래 공격 키 아이콘(쿨다운 표시), 위쪽 가운데 방 보상(기억).
- 산나비: 체력 막대 하나, 시간이 지나면 찬다.
- 우리에게: 지금 HUD는 하단 전체에 조작 키 설명 막대가 늘 떠 있고 체력·진심 칸이 위쪽에 흩어져 있다. 조작 설명은 처음 2판만 → 일시정지 메뉴로. 체력·진심은 왼쪽 아래 한 덩어리, 발도 준비 상태는 주인공 발밑 표시로(눈이 주인공에서 안 떠나게). 위쪽 가운데는 목표 한 줄(계단 봉인 · 강적 n 같은 것).

## 타이틀
- 핫라인 마이애미·카타나 제로: 움직이는 장면 위에 네온·VHS 느낌 메뉴, 음악이 첫인상(기억).
- 셀레스트: 산 그림 하나에 메뉴 몇 줄(기억).
- 우리에게: 을지로 옥상 밤 장면(남산타워, 깜빡이는 간판) 위에 로고 + 이어하기·새로 시작·설정·끝내기. 설정에 음량. 새로 시작은 덮어쓰기 확인을 한 번 받는다.
