# 🔍 레퍼런스 역설계: 소녀전선 (Girls' Frontline, 2016)

> 우리 게임의 "대원 수집 · 편성 · 파견 · 사무소 생활" 축과 가장 닮은 모바일 게임. 무엇을 가져오고 무엇을 피할지 정리.
> 출처: Wikipedia, IOP Wiki, Gamepress, BlueStacks (2026-10 확인).

## 1. 구조 한눈에
```
인형(대원) 획득 ─▶ 제대(5명) 편성 ─▶ ① 작전 지도에서 전투
                               ├▶ ② 군수 지원(시간 걸리는 파견 → 자원)
                               └▶ ③ 모의 작전(훈련용 재료 파밍)
숙소: 가구 배치 → 쾌적도 보너스, 선물 → 호감도 → 전투 능력치 ↑
```

## 2. 핵심 시스템
| 시스템 | 방식 | 왜 잘 됐나 |
|--------|------|-----------|
| **작전 지도** | 노드(점)로 된 지도에서 제대를 한 칸씩 옮기는 **턴제 전략**. 적 제대도 움직임. 본부 점령·헬기장 확보 | 전투는 자동이어도 "어디로 갈지"가 머리 쓰는 재미 |
| **전투** | 대부분 **자동 실시간.** 플레이어는 스킬 발동 타이밍과 **3×3 칸 위치 이동**만 | 조작 부담이 적어 모바일에 적합, 연출 비용 낮음(옆모습 스프라이트) |
| **진형 버프** | 인형마다 **특정 칸 모양에 서 있는 아군을 강화** (피해·명중·회피·사속) | 숫자 데이터만으로 "누구를 어디에 둘까" 깊이 생성 → 편성이 퍼즐이 됨 |
| **보급** | 전투마다 탄약·식량 소모, 특정 노드에서 재보급 | 자원 경제가 출동에 비용을 매김 |
| **군수 지원** | 제대를 시간 걸리는 임무에 보내 자원 획득. 성공률은 제대 평균 레벨 | 접속 안 해도 수입 → 재접속 이유. **우리 "2분대 파견"과 같음** |
| **숙소** | 가구 세트 → 쾌적도, 선물 → 호감도 → 능력치 | 꾸미기가 성장과 연결 |
| **더미 링크** | 같은 인형을 겹쳐 인원·능력치 ↑ | 중복 획득을 쓸모 있게 |

## 3. 우리 게임에 가져올 것 (좋은 방향)
| 가져올 것 | 우리 버전 | 모듈 |
|----------|----------|------|
| **군수 지원** | 대원을 정화된 구역에 보내 시간 지나면 자원 ("2분대 파견"). 성공률 = 대원 레벨·궁합. **밤 플레이보다 많이 벌지 못하게 상한** | economy / dispatch (Gate 3) |
| **진형 칸 버프 (축소판)** | 조 편성에서 **동료 배치 칸 1~2개**: 앞에 둔 동료/뒤에 둔 동료가 주는 보너스가 다름. 데이터만으로 편성 깊이 | party (Gate 2) |
| **작전 지도(노드)** | 서울 지도에서 구역을 점(노드)으로 → 그날 갈 의뢰 고르기. 노드끼리 이동 비용(막차 시간?) | contract / Seoul map (Gate 3) |
| **숙소 = 옥탑방 꾸미기** | 가구 → 쾌적도 → 트라우마 회복 속도 ↑ (능력치 직접 ↑는 피함) | hub (Gate 3+) |
| **중복 획득 활용** | 같은 괴이를 또 영입하면 "인연 단계" ↑ (능력·대사 해금) | recruit |
| **대여 시장의 원형** | 소녀전선엔 없지만 "친구 제대 지원" 개념과 유사 → 우리 대여 시장 (Gate 4) | rental |

## 4. 피할 것
| 피할 것 | 이유 |
|--------|------|
| 확률 뽑기(제조) 중심 | 과금 규칙 위반 위험 ([monetization.md](../design/monetization.md)). 우리는 영입 = 플레이 |
| 자원 4~5종 | "덕지덕지" 원인. 재화 최대 3개 규칙 유지 |
| 자동 전투만 | 우리는 직접 조작(액션 또는 칸 턴제)이 핵심 |
| 강화 재료 노가다(모의 작전 반복) | 1인 개발로 콘텐츠 공급 불가 → 지루함만 남음 |

## 5. 결론: 우리 게임의 "두 겹" 구조
- **안쪽(직접 플레이):** 불가사의 던전처럼 의뢰 → 던전 → 영입. 소장을 직접 조작.
- **바깥쪽(경영·수집):** 소녀전선처럼 대원 편성(칸 버프) · 군수 파견 · 숙소(옥탑방) · 대여.
- 바깥쪽은 **숫자 데이터 + 메뉴 UI**라서 그림 부담이 적고, 1인 개발로 확장하기 쉬움.
