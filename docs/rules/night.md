## 한 판의 흐름
의뢰판에서 고른 의뢰가 층 목록이 된다(`office/contracts.ts` `offerFloors`). 층을 순서대로 하고, 층을 넘길 때마다 강화 카드 3장 중 1장. 체력·진심 게이지·전리품은 다음 층으로 이어진다. 층을 넘길 때 카드 수는 트라우마가 2 이상이면 2장([성장 규칙](growth.md)). 끝나는 길은 넷: 성공(마지막 층 계단, 보스 정화, 또는 목표 층에서 "귀환"을 고름 — `run.ts` `finishAtGoal`), 공중전화 귀환, 목표 실패(구조 대상이 홀리거나 쓰러짐, 추격 표적이 마지막 층에서 달아남), 쓰러짐(일시정지의 "의뢰 포기"도 쓰러짐과 같게 처리). 목표 층은 [한 층 규칙](floor.md#층-목표와-계단).

## 능력치 (`computeExorcistStats`)
최종 능력치는 저장하지 않고 출동마다 기본값 → 트레이닝 → 패시브 기술 → 카드 순으로 다시 계산한다(ARCHITECTURE 규칙 7). 소장의 손맛을 정하는 숫자(이동·돌진·휘두르기 간격·발도 재사용·받아치기 창·리치·피격 무적·영력 끌어오기)는 전부 능력치(`Stats`) 안에 있고, 주인공·무기 데이터 표는 기본값만 준다. 트레이닝 줄별 값은 [성장 규칙](growth.md).

| 기본값 | 지금 | 위치 |
|-------|-----|------|
| 최대 체력 | 12 | `protagonist.data.ts` `maxHp` |
| 이동 속도 | 초당 5칸, 휘두르는 동안 0.7배 | `moveSpeed`, `swingMoveMult` |
| 돌진 | 초당 15칸 × 0.18초, 앞 0.14초 무적, 재사용 0.45초, 1번 모아 둠 | `dash*` |
| 피격 무적 | 0.7초 | `hurtIframes` |
| 베기 | 3, 3타째 +1, 리치 1.6칸, 간격 0.28초, 3타 뒤 0.42초 | `weapons.data.ts` `slash`, `comboBonus`, `reach`, `swingTime`, `finisherRecovery` |
| 발도 | 앞 크게 베기 7 / 받아치기·일섬 12, 재사용 1초, 받아치기 창 0.22초, 자세 0.12초 | `drawSlash`, `draw`, `drawCooldown`, `parryWindow`, `drawStartup` |
| 진심 게이지 | 5칸, 맞힌 베기마다 +1, 가득이면 발도가 일섬 | `focusMax` |
| 검신 노출 | 발도 성공 뒤 3초, 베기 +1 | `bareTime`, `bareSlashBonus` |
| 영력 끌어오기 | 2.2칸 | `dungeon.data.ts` `pickupMagnet` |

## 강화 카드 (`cards.data.ts`)
층을 넘길 때 기본 덱 + 들고 간 무기 덱에서 아직 안 가진 카드 3장을 랜덤으로 보여 준다(`CARD_OFFER_COUNT`). 한 판이 끝나면 카드는 사라진다.

| 카드 | 효과 |
|------|------|
| 을지로 맷집 | 최대 체력 +4, 체력 4 회복 |
| 편의점 쌍화탕 | 체력 8 회복 |
| 소금 한 줌 | 층에 들어갈 때마다 피해 1번 막는 보호막 |
| 원한 흡수 | 처치 시 35%로 체력 1 회복 |
| 영력 냄새 | 처치 시 영력 +2 |
| 신문지 두 겹 | 베기 +1 |
| 푸른 벼락 | 발도 피해 +4 |
| 귀찮지만 진심 | 진심 게이지가 1칸 빨리 참 |
| 찢어진 신문지 | 받아치기 후 검신 노출 +2초 |
| 세 번째는 진심 | 연속 3타째 피해 +2 |

## 정산 (`settle.ts`, 숫자는 `penalties.data.ts`)
| 결과 | 전리품 | 수임료 | 트라우마 | 의뢰 |
|------|-------|-------|---------|------|
| 성공 | 전부 | 끝낸 의뢰들의 보수 합(합동 출동) | 0 | 끝남, 동네 오염 감소 |
| 공중전화 귀환 | 전부(`extractLootKeepRatio` 1) | 없음 | 0 | 판에 남음 |
| 목표 실패 | 전부(`failLootKeepRatio` 1) | 없음 | +1(`failTrauma`) | 판에 남음 |
| 쓰러짐·포기 | 절반(`deathLootKeepRatio` 0.5) | 없음 | +1(`deathTrauma`) | 판에 남음 |

심연 파편: 그 밤에 얻은 것(현상수배·추격 표적, 메인 보스, 계속 끝 보물 방, 괴이 소굴)은 쓰러지거나 포기하지 않는 한 전부 가져간다(`settle.ts`). 표적 의뢰를 실패하면 표적이 한 단계 세진다([낮 규칙](office.md)).

전리품(영력)은 정산 때 같은 단위의 돈이 된다. 트라우마 효과와 회복은 [성장 규칙](growth.md). 해결한 의뢰 수(`solved`)는 성공일 때만 +1이고 사무소 해금에 쓰인다([허브 규칙](hub.md)).
