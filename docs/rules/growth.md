# 🧮 성장 규칙 (트레이닝 · 기술 · 트라우마 · 시설 · 보급품)

← [장부 목록](README.md) · 기획 이유: [성장·시설·트라우마](../design/3-growth/progression.md) · 근거: [돈으로 강해지는 구조](../reference/progression-systems.md)
계산 코드: `src/systems/growth/`(`training.ts`, `skills.ts`, `facilities.ts`, `trauma.ts`, 출동 짐 `loadoutOf`), 능력치 합산은 `src/systems/run/stats.ts`, 기술·보급품 효과는 `src/registry/perkEffects.ts`, 액티브는 `src/systems/rift/skills.ts`. 숫자: `src/data/training.data.ts`, `skills.data.ts`, `facilities.data.ts`, `penalties.data.ts` `TRAUMA`. 테스트: `tests/growth.test.ts`, `balance.test.ts`.

재화는 둘이다. 돈(밤에 줍는 영력이 정산 때 1:1로 돈이 됨)은 월세·트레이닝·시설·보급품·자본 치료에, 심연 파편은 기술에만 쓴다.

## 트레이닝 (돈, 소장 책상)
영구 능력치. 한 줄 = 능력치 하나, 단계마다 조금씩. 다 찍어도 피해 +20%, 체력 +33%, 이동 +10% 정도로, 뱀파이어 서바이버 상점 폭(피해 +25%, 체력 +30%, 이동 +10%)에 맞췄다.

| 갈래 | 줄 | 단계당 | 최대 | 다 찍으면 | 기본 값 |
|------|----|-------|-----|---------|--------|
| 완력 | 베기 피해 | ×4% | 5 | +20% | 180 |
| | 발도 피해(그냥 발도·받아치기·일섬 모두) | ×4% | 5 | +20% | 180 |
| | 베기 리치 | +0.05칸 | 3 | 1.6 → 1.75칸 | 300 |
| 손놀림 | 휘두르기 간격 | −3% | 5 | −15% | 220 |
| | 발도 재사용 | −5% | 4 | 1.0 → 0.8초 | 220 |
| | 3타 뒤 숨 고르기 | −5% | 3 | −15% | 180 |
| 몸놀림 | 이동 속도 | +2% | 5 | +10% | 180 |
| | 돌진 재사용 | −4% | 5 | 0.45 → 0.36초 | 220 |
| | 돌진 거리 | +5% | 2 | +10% | 220 |
| 담력 | 최대 체력 | +1 | 4 | 12 → 16 | 220 |
| | 받아치기 여유 | +0.01초 | 3 | 0.22 → 0.25초 | 380 |
| | 맞은 뒤 무적 | +0.05초 | 2 | 0.7 → 0.8초 | 300 |
| 진심 | 진심 게이지 칸 수 | −1칸 | 1 | 5 → 4칸 | 750 |
| | 검신 노출 시간 | +0.5초 | 2 | 3 → 4초 | 220 |
| 수완 | 영력 끌어오기 범위 | +10% | 3 | +30% | 120 |

값 = 기본 값 × (그 줄에서 이미 산 단계 + 1) × (1 + 0.02 × 지금까지 산 전체 횟수), 10원 단위(`trainingPrice`). 같은 줄을 연달아 사면 빨리 비싸지고, 무엇을 사든 전체가 조금씩 오른다. 52단계 전부 약 4만 6천. 주 수입 2,500에서 조금씩 늘고 그 70%를 쓴다고 치면 첫 주 7단계, 4주 20단계, 8주 33단계, 다 찍는 데 약 17주(플레이 전 추정).

규칙 하나: 줄을 어떻게 섞어도 "일반 베기 최대(막타 + 검신 노출) < 그냥 발도 < 받아치기·일섬" 순서가 지켜져야 한다. 모든 줄 만렙에서 베기 최대 5.6 < 발도 8.4 < 14.4(테스트로 고정).

봇 기준(이야기 의뢰, 8씨앗): 트레이닝 0 → 서투른 봇 0/8, 읽는 봇 8/8 평균 184초. 만렙 → 서투른 봇 0/8, 읽는 봇 8/8 평균 172초. 숫자를 더 키우면 서투른 봇이 깨기 시작하는지 `balance.test.ts`가 잡는다.

줄 추가 = `training.data.ts`에 한 줄 + `ids.ts` `TrainingId` + 한글·영어 이름 한 줄. 계산 코드는 표를 그대로 읽는다.

## 기술 (심연 파편, 소장 책상 2번 탭)
패시브: 검·발·눈 3갈래 × 3칸, 칸마다 A/B 중 하나만 켜진다(하데스 거울 방식). 칸을 여는 데 파편 1/2/3개(갈래마다 1→2→3칸 순서), 쪽 바꾸기는 공짜. 다 열면 18개.

| 칸 | A | B |
|----|---|---|
| 검 1 | 돌진 베기: 돌진 끝에 앞을 한 번 벤다(베기 피해) | 3타 파문: 3타 막타가 주변 한 바퀴(리치 +1칸)도 절반 피해로 |
| 검 2 | 받아친 기세: 받아치기 성공 시 진심 +2 | 칼집 소리: 그냥 발도에 맞으면 0.6초 굳음 |
| 검 3 | 남은 진심: 일섬 뒤 진심 2칸 남음 | 벗겨진 신문: 검신 노출 중 맞힐 때마다 노출 +0.3초(최대 2배) |
| 발 1 | 소금 자국: 돌진 자리에 1.5초 소금, 도깨비불이 닿으면 사라짐 | 되받아 빠지기: 받아치기 성공 시 돌진 즉시 충전 |
| 발 2 | 두 번 돌진: 돌진 2번까지 모아 둠 | 그림자 걸음: 돌진 내내 무적 |
| 발 3 | 스치기: 돌진으로 공격을 흘리면 진심 +2 | 질주: 공격 없이 1초 넘게 달리면 다음 공격까지 +15% 속도 |
| 눈 1 | 귀신 눈: 화면 밖 강적이 가장자리 화살표로 | 영력 눈: 영력 끌어오기 2배 |
| 눈 2 | 숨 고르기: 그 층에서 한 대도 안 맞고 계단 → 체력 2 | 원한 먹기: 강적 처치 시 체력 1 |
| 눈 3 | 마지막 숨: 하룻밤 한 번, 쓰러질 공격을 체력 1로 | 욕심: 강적이 영력 3 더 |

액티브(L 키, 전투 버튼 넷째 칸): 파편 2개로 배우고 하나만 단다(처음 배운 것이 자동으로 달림).

| 액티브 | 효과 | 재사용 |
|-------|------|-------|
| 부적 던지기 | 조준 방향으로 초당 14칸, 8칸까지. 처음 맞은 괴이에 피해 4 + 1.5초 기절(보스는 기절 없음) | 6초 |
| 결계 펴기 | 2초 무적 + 반지름 2칸 원, 원 안 도깨비불이 탄다 | 14초 |
| 소금 뿌리기 | 3.5칸 안 도깨비불 전부 정화, 강적 0.6초 굳음 | 10초 |

심연 파편 얻는 곳: 현상수배(1 + 놓친 횟수), 추격 1, 메인 스토리 보스 3, 목표를 넘겨 끝까지 간 마지막 층 보물 방 1, 괴이 소굴 35%. 쓰러지거나 포기하면 그 밤 파편은 없음.

전부 동작을 테스트로 확인했다(`tests/perks.test.ts`, 2026-10-27). 돌진 베기는 처음엔 마우스 조준 쪽을 베고 휘두르는 모습도 없어서 안 되는 것처럼 보였다 — 지금은 돌진한 방향을 베고 휘두르기가 보인다. 귀신 눈·지도 사본은 화면 화살표라 눈으로 확인.

기술 효과는 카드와 같은 훅 자리(`registry/hookPoints.ts`)에 끼운다. 숫자만 바꾸는 쪽(두 번 돌진·그림자 걸음·영력 눈)은 `skills.data.ts`의 `mods`가 능력치에 더한다.

## 트라우마 (`penalties.data.ts` `TRAUMA`)
쌓이는 곳: 쓰러짐·포기 +1, 목표 실패 +1.

| 트라우마 | 효과 |
|---------|------|
| 2 이상 | 층을 넘길 때 강화 카드가 3장이 아니라 2장 |
| 4 이상 | 출동할 때 체력 −2로 시작(최대 체력은 그대로) |
| 6 이상 | 출동 불가(의뢰판 출동 버튼이 잠김) |

회복(소파): 휴식하기 = 그날 밤 출동 없이 다음 아침으로(월세·오염·마감은 평소대로 흐름), 트라우마 −2 −소파 단계. 자본 치료 = 1,000원에 −2, 출동 가능. 진정제 사용 = 진정제 아이템이 생기면 켠다(지금은 자리만).

## 시설 (돈, 경리 장부의 "시설 공사")
| 시설 | 단계 값 | 1단계 | 2단계 | 3단계 |
|------|--------|------|------|------|
| 경리 책상 | 600 / 1,200 / 2,000 | 의뢰판 +1장(공사 즉시 한 장 더 올라옴) | 안 가 본 동네 괴이도 보임 | 새로 올라오는 일반 의뢰 마감 +1일 |
| 부적 작업대 | 500 / 1,000 / 1,800 | 설치(정수기 옆에 생김) · 소금 한 봉 | + 박카스 | + 지도 사본 |
| 낡은 소파 | 800 / 1,500 | 휴식하기 −1 더 | 휴식하기 −1 더 | — |

## 보급품 (돈, 부적 작업대)
출동 전에 하나만, 고를 때 값을 낸다(다른 것으로 바꾸면 앞의 것은 환불). 그 밤 시작에 효과가 들어가고 사라진다. 휴식하는 날엔 그대로 남는다.

| 보급품 | 값 | 효과 |
|-------|---|------|
| 소금 한 봉 | 60 | 첫 층에서 공격 2번 막음 |
| 박카스 | 100 | 체력이 처음 절반 아래로 떨어질 때 6 회복 |
| 지도 사본 | 120 | 첫 층 계단 쪽 화살표 |
