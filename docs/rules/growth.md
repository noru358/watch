## 효과 부품 (모든 기술·장신구 특수·보급품의 공통 언어)
한 줄 = 언제(훅 이름 또는 `onCast`) + 조건(없어도 됨) → 부품 하나 + 숫자 [+ 재사용 초]. 부품은 `registry/effects/parts/` 파일 하나씩: 추가타(hit), 상태이상(status), 투사체(shot), 장판(zone), 자원 얻기(gain), 잠깐 능력치(buff), 배율(scale), 정화(cleanse), 스택 쌓기(stack)·쓰기(spend), 한 번 더(echo), 순간이동(blink), 영력 터뜨리기(burst), 버티기(save), 줍기(collect). 조건: 확률, 체력 아래·위, 대상 종류, 공격 종류, 그냥 발도, 막타, 검신 노출, 달리는 중(calm 초), 이 층 무피격, 스택 수, 표식, 층·밤마다 한 번, 첫 층.

규칙: 부품이 부른 타격·처치는 다시 줄을 부르지 않는다(무한 연쇄 방지 — 리스크 오브 레인 2의 proc 규칙). 스택은 이름으로 공유한다(듀오·액티브가 같은 스택을 읽는다). 층마다 상태는 층 객체에 붙어 층이 바뀌면 사라지고, "밤에 한 번"은 `f.used`에 남는다. 새 기술 = 데이터 한 줄 + 이름·설명 i18n. 새 동작이 필요할 때만 부품 파일 하나.

## 기술 v2 (심연 파편, 소장 책상 2번 탭)
패시브: 검·발·눈·솜씨 4갈래 14칸, 칸마다 둘~넷 중 하나만 켜진다(하데스 거울 방식, 바꾸기는 공짜, A / D). 칸은 갈래 안에서 위 칸부터 연다. 4층 칸은 고를 게 셋·넷이다.

| 칸 | 파편 | 고를 수 있는 것 |
|---|---|---|
| blade1 | 1 | 돌진 베기: 돌진이 끝날 때 앞을 한 번 벤다. / 3타 파문: 3타 막타가 주변 한 바퀴도 절반 피해로 벤다. |
| blade2 | 2 | 받아친 기세: 받아치기에 성공하면 진심 게이지 2칸. / 칼집 소리: 그냥 발도에 맞은 괴이가 잠깐 굳는다. |
| blade3 | 3 | 남은 진심: 일섬을 쓰고 나서 진심 게이지가 2칸 남는다. / 벗겨진 신문: 검신 노출 중 맞힐 때마다 노출이 조금 늘어난다. |
| blade4 | 4 | 뒤따르는 칼: 휘두를 때 25% 확률로 앞을 60% 위력으로 한 번 더. / 기세: 베기로 맞힐 때마다 기세 +1(최대 5), 기세당 베기 피해 +3%. 3초 안 때리면 사라짐. / 부정 타기: 베기에 맞은 괴이에 부정 1스택(초당 1, 최대 3스택, 4초). |
| step1 | 1 | 소금 자국: 돌진한 자리에 소금이 남아 도깨비불이 닿으면 사라진다. / 되받아 빠지기: 받아치기에 성공하면 돌진이 바로 다시 찬다. |
| step2 | 2 | 두 번 돌진: 돌진을 두 번까지 모아 둔다. / 그림자 걸음: 돌진하는 내내 맞지 않는다. |
| step3 | 3 | 스치기: 돌진으로 공격을 흘리면 진심 게이지 2칸. / 질주: 공격하지 않고 1초 넘게 달리면 다음 공격 전까지 15% 빨라진다. |
| step4 | 4 | 서리 소금: 발도에 맞은 괴이가 2초 동안 30% 느려진다. / 날 선 돌진: 돌진이 닿는 괴이를 베기 30%로 벤다(0.2초마다). / 버티기: 받는 피해 −20%, 대신 이동 −5%. |
| eye1 | 1 | 귀신 눈: 화면 밖 강적이 가장자리에 표시된다. / 영력 눈: 영력을 두 배 멀리서 끌어온다. |
| eye2 | 2 | 숨 고르기: 한 번도 안 맞고 층을 넘기면 체력 2 회복. / 원한 먹기: 강적을 쓰러뜨리면 체력 1 회복. |
| eye3 | 3 | 마지막 숨: 하룻밤에 한 번, 쓰러질 공격을 체력 1로 버틴다. / 욕심: 강적이 영력을 3 더 떨어뜨린다. |
| eye4 | 4 | 벼랑 끝: 체력이 1/4 아래면 주는 피해 ×1.3. / 복수: 맞으면 3초 동안 베기 피해 ×1.2. / 원혼 폭발: 강적을 쓰러뜨리면 근처 셋까지 베기 ×1로 터진다. / 영력 털기: 강적을 맞힐 때 10% 확률로 영력 1이 튄다. |
| craft1 | 1 | 문턱 자석: 층을 넘길 때 바닥에 남은 영력을 다 주워 간다. / 지름길 냄새: 모든 층에서 계단 쪽 화살표가 보인다. |
| craft2 | 2 | 결계 솜씨: 결계 의뢰의 원이 15% 빨리 찬다. / 보살핌: 구조 의뢰인 체력 +30%. / 새벽 손님: 첫차까지 기다릴 시간 −15%. |

## 트라우마 (`penalties.data.ts` `TRAUMA`)
쌓이는 곳: 쓰러짐·포기 +1, 목표 실패 +1.

| 트라우마 | 효과 |
|---------|------|
| 2 이상 | 층을 넘길 때 강화 카드가 3장이 아니라 2장 |
| 4 이상 | 출동할 때 체력 −2로 시작(최대 체력은 그대로) |
| 6 이상 | 출동 불가(의뢰판 출동 버튼이 잠김) |

회복(소파): 휴식하기 = 그날 밤 출동 없이 다음 아침으로(월세·오염·마감은 평소대로 흐름), 트라우마 −2 −소파 단계. 자본 치료 = 1,000원에 −2, 출동 가능. 진정제 사용 = 진정제 아이템이 생기면 켠다(지금은 자리만).

## 장신구 (돈 + 심연 파편, 소장 책상 3번 탭)

주옵션은 칸의 후보 셋 중 하나, 단계(+0 ~ +10)마다 커진다. 강화는 돈만 들고 실패가 없다(값 = 60 × 1.4^단계 × 등급 배율). 부옵션은 등급만큼 무작위(주옵션과 같은 능력치는 안 나옴), 파편으로 하나씩 다시 굴린다(1 → 2 → 3개, 그 뒤 3개). 녹이면 단계와 등급만큼 돈.

부옵션 후보: 베기 피해, 발도 피해, 치명 확률, 치명 피해, 강적 피해, 도깨비불 피해, 보스·표적 피해, 최대 체력, 받는 피해, 어둠 저항, 회복량, 이동 속도, 돌진 재사용, 진심 차는 양, 영력 획득, 파편 확률, 결계 채우기, 구조 의뢰인 체력, 첫차까지 시간.

전설 특수(효과 부품 한 줄): 원혼 폭발(강적을 쓰러뜨리면 근처 셋까지 터진다.) / 뒤따르는 칼(휘두를 때 20% 확률로 앞을 50% 위력으로 한 번 더.) / 서리 방울(맞힌 괴이가 1.5초 25% 느려진다(1초마다).) / 벼랑 끝(체력 1/4 아래면 주는 피해 ×1.25.) / 영력 털기(강적을 맞힐 때 8% 확률로 영력 1.) / 복수(맞으면 3초 동안 베기 피해 ×1.15.) / 부정 구슬(베기에 맞은 괴이에 부정(초당 1, 3초, 최대 2스택).).
