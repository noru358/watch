# ☎️ 의뢰·밤 한 판 모듈

**담당 코드:** `src/data/contracts.data.ts`(의뢰 목록·보상), `src/systems/contract/`(의뢰 생성·진행), `maps/`(방 조각)

## ✅ 결정
- **의뢰 1건 = 밤 1판 = 10~15분.**
- 흐름: 의뢰 접수 → 현장 도착 → **방 5~8개** 탐색·전투 → 원인 귀신(보스) 해결 → 정산(→ [run-result.md](run-result.md))
- 의뢰 종류 두 가지 섞기:
  - **스토리 의뢰** — 직접 쓴 이야기. 순서 고정, 보스급 귀신 영입 연결(→ [recruit.md](recruit.md)), 월세·빚 이야기와 엮임(→ [economy.md](economy.md))
  - **일반 의뢰** — 자동 생성. 현장·귀신 조합·보상을 데이터 표에서 뽑음 (SeededRNG 사용)
- 현장 예시: 을지로 노포 지하, 폐모텔, 막차 끊긴 지하철역.
- 현장 맵은 **조립식**: 구역마다 타일셋 1개 + 방 조각 여러 개를 섞음 (→ [art.md](art.md))

## Gate 1 범위
을지로 의뢰 1건, 방 몇 개, 보스 1마리, 탈출(보스 처치 or 공중전화).

## 🧪 현재 시험판 (2026-10-24, 확정 아님 — 플레이 후 수정)
- 방 7개: 전투 3 → 공중전화 → 전투 2 → 보스(윤전기 귀신)
- 전투 방: 문 잠김 → 귀신 2웨이브 → 정화 완료 → 기질 3개 중 1개 → 위쪽 문
- 공중전화 방: J로 귀환(전리품 유지, 수임료 없음) 또는 문으로 계속
- 보스: 탄막(원형) → 조준 연사 → 처녀귀신 소환 반복, 체력 절반에서 네온 2페이즈
- 귀신 3종: 처녀귀신(순간이동), 달걀귀신(맞으면 시야 어두워짐), 지하철 망령(일직선 돌진)
