# 🎬 실제 플레이 흐름 (제안 — 플레이 후 수정)

> 여러 모듈을 엮어 "실제로 어떻게 플레이되나"를 보여주는 문서. 규칙의 원본은 각 모듈 문서.

## 레퍼런스 게임
| 게임 | 가져올 것 |
|------|----------|
| **Hades** | 방 단위 런, 클리어 보상 3택(축복 = 우리 기질 덱), 런 사이 허브에서 대화·성장, 죽어도 스토리 진행 |
| **Dave the Diver** | 낮/밤 두 가지 일(잠수 ↔ 초밥집 경영), 만담 캐릭터들, 가벼운 톤 |
| **Moonlighter** | 밤 던전 파밍 → 낮 가게 운영, 전리품이 곧 돈 |
| **Hyper Light Drifter / Katana ZERO** | 탑다운 픽셀 근접 전투, 한 번에 베는 일섬의 쾌감 |
| **Sekiro** (발도만) | 상대 공격 타이밍에 맞춘 패링 → 큰 보상 |
| **Recettear** | 빚·월세 마감이 돈 벌 이유를 만듦 |
| 은혼 · 혈계전선 (애니) | 톤과 세계관 |

## 조작 (사인검, 버튼 4개)
| PC | 행동 |
|----|------|
| WASD | 이동 |
| J | 신문지 칼 휘두르기 (3타 콤보, 칼집째) |
| K | 구르기 (무적) |
| L | **발도** — 괴이 공격 직전 "!" 타이밍에 누르면 패링 + 일섬. 진심 게이지가 꽉 차면 아무 때나 일섬 |
| ; | 동료 호출 (Gate 2부터) |

- 진심 게이지: 평타를 맞힐수록 참. "평소엔 대충, 진심일 때 간지"를 시스템으로 표현.
- 발도 실패(타이밍 빗나감): 짧은 빈틈 → 위험 부담.

## 하루 (게임 안 1일 = 현실 15~20분)
1. **낮, 옥탑방** — 월세 마감 D-n 표시. 의뢰 2~3개 중 선택 (Gate 2부터 경리가 브리핑)
2. **출동** — "아 비 오는데 귀찮게…" 슬리퍼 끌고 철문 나섬
3. **밤, 현장 한 판 (10~15분)** — 방 5~8개, 방마다 기질 카드 3택, 중간에 공중전화(귀환 선택), 끝에 보스
4. **정산** — 수임료 + 전리품. 실패 시 트라우마 + 전리품 일부 손실
5. **다음 날** — 돈으로 월세·사인검 연마·새 기질 카드 해금. 스토리 대화

## 일주일
7일마다 월세 날. 못 내면 빚 + 스토리 이벤트. 장(章)마다 새 구역·보스·식구 해금.
