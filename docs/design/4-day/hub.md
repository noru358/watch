# 🏢 허브(옥탑방 사무소) 모듈

**담당 코드 (예정):** `src/scenes/hub/`(걸어다니는 사무소), `src/ui/features/<기능>/`(말 걸면 열리는 창), `src/data/lobby.data.ts`(기능 등록표)
**지금 코드:** `src/ui/OfficeApp.tsx` — Gate 1 임시 사무소 화면 (출동 버튼만)

## ✅ 결정
### 장소와 분위기
- **을지로 인쇄골목 건물 옥탑방** 사무소. 남산타워 보이는 노을, 시티팝 (→ [world.md](../1-foundation/world.md))
- 허브는 옥탑방 + 골목 **한 화면**. 어디든 3초 안에 닿는 크기.

### PC식 허브 = 소울류 "걸어다니며 말 걸기"
- 화면에 버튼을 덕지덕지 붙이지 않음. **하단 메뉴 줄·상단 재화 바 상시 표시 없음.**
- 식구 앞에서 `E` → 그 사람의 메뉴가 열림. 옥탑 **철문으로 걸어 나가면 출동.**
- `Esc` → 전체 메뉴 (상태 · 소지품 · 설정). 재화는 돈 쓸 때만 표시.
- 시작 흐름: 타이틀 → 세이브 슬롯 → 사무소.
- 모바일판(나중): 사람·물건을 탭하면 자동으로 걸어감.

### 사무소 식구 (전투 동행 안 함, 사무소 전담)
| 식구 | 설정 | 말 걸면 | 해금 |
|------|------|--------|------|
| 🧾 잔소리꾼 경리 겸 알바생 | 평범한 사람(무당 아님). 옥탑방에 얹혀사는 취준생, 실질적 서열 1위 | 의뢰판 · 월세 정산 · 파견 브리핑 | 스토리 |
| 🐈 뚱뚱한 삼색 고양이 영물 | 힘이 봉인된 백 년 묵은 영물, 입만 살아있음 | 유물 감정 · 괴이 암시장 (게임 재화로만) | 스토리 |
| 1층 집주인 할머니 | 🤔 보류 — 월세 압박 담당 후보 | — | — |

처음엔 소장 혼자 → 의뢰 전화도 소장이 직접 받음.

## 메뉴 목록 (누구에게 말 걸면 열리나)
| 메뉴 | 여는 곳 | 시점 |
|------|--------|------|
| 🌙 출동 (의뢰 고르고 나가기) | 철문 (경리 해금 전엔 전화기) | Gate 1 |
| ⚙️ 설정 | `Esc` 메뉴 | Gate 1 |
| ☎️ 의뢰판 · 월세 | 경리 | Gate 2 |
| 🔍 감정 · 암시장 | 뚱냥이 | Gate 2 |
| 🤝 조 편성 | 화이트보드 ([party.md](../3-growth/party.md)) | Gate 2 |
| 🚐 파견 | 경리 | Gate 3 |
| 🏠 꾸미기 | 소파 | Gate 3+ |
| 🔁 대여 | 공중전화 | Gate 4 |

해금 전 메뉴는 **아예 안 보임** (잠금 아이콘으로 자리 채우지 않기).

## 확장 구조: "등록표 한 줄 = 메뉴 하나"
```ts
// src/data/lobby.data.ts (예정)
export const LOBBY_FEATURES: Record<LobbyFeatureId, LobbyFeatureData> = {
  contracts: { labelKey: 'lobby.contracts', npc: 'bookkeeper', unlock: 'story_ch1' },
  appraise:  { labelKey: 'lobby.appraise',  npc: 'cat',        unlock: 'story_ch2' },
  // 새 기능 = 여기 한 줄 + src/ui/features/<이름>/ 화면 파일 하나
};
```
- 창 여닫기는 `openFeature(id)` / `closeFeature()` 하나로만 → 입력 계단(`modal`)도 여기서 자동 처리 (ARCHITECTURE 규칙 4).
- `Esc` = 열린 창 닫기. 닫은 직후 클릭 없이 키가 바로 먹어야 함.
