## 결정
- 긴장 장치는 밀린 월세와 빚(7일마다). 레세티아처럼 가벼운 압박: 돈을 벌 이유를 만들지 게임오버를 만들지 않는다(모자라면 빚).
- 재화는 둘(2026-10-28 사용자 확정): 돈과 심연 파편. 영력은 밤에 줍는 돈(정산 때 1:1, 화면에 "영력 n = ₩n"). 평판은 쓰지 않는 경험치. 재화는 늘려도 3개까지, 쓸 때만 보인다.
- 경영이 게임의 반쪽이다(2026-11-10 사용자: "경영적 요소만 넣으란 게 아니라 경영겜이어야"). 옛 결정 "낮 자동 수입은 밤 플레이보다 적게"와 "경영은 가볍게"는 뒤집었다. 직원이 버는 돈이 사무소를 키우되, 지역 해금·보스·희귀 보상은 소장이 직접 뛴 밤에서만 나온다.

## 경영 구조 (2026-11-10 확정, 📝 아직 안 지음)
- 나눌 것이 있어야 경영이다. 매일 밤 의뢰판에는 사무소가 다 못 덮을 만큼 의뢰가 뜬다. 소장은 하나를 직접 뛰고(액션), 나머지는 소속 퇴마사를 배정한다(자동, 성공률을 미리 보여 줌). 못 덮은 의뢰는 대가가 있다.
- 직원: 급여를 받고, 다녀오면 트라우마가 쌓이고, 쉬게 하거나 치료하거나 훈련시킨다. 장신구와 트레이닝은 누구에게 줄지 고르는 문제가 된다. 평판 등급이 고용 인원과 의뢰 등급을 정한다.
- 같은 직원이 밤에 따라가면 호출 스킬, 보내면 그 밤에 못 쓴다(어쌔신 크리드 브라더후드의 딜레마).
- 대여: 우리 직원으로 못 덮는 의뢰가 있으면 다른 사무소에서 빌려 오고, 노는 직원은 빌려주고 수수료를 받되 그동안 못 쓴다. NPC 사무소부터.
- 참고: 소녀전선(직접 지휘 + 군수 + 친구 지원 제대), 디스 이즈 더 폴리스(모자란 인원을 사건에 배정), 다키스트 던전(명단과 스트레스). 비교는 [파견 게임](../../reference/dispatch-games.md).
- 짓는 순서: 아래 "경영 뼈대 설계"의 1 → 2 → 3 → 4.

## 경영 뼈대 설계 (2026-11-11, ✅ 1~3단계 들어감 — 규칙은 [직원 규칙](../../rules/staff.md))
**직원.** 둘로 나뉜다. 이야기로 들어오는 식구(장마다 한 명, 이름·대사·호출 스킬이 있다 → [이야기 바이블](../1-foundation/bible.md))와, 돈 주고 쓰는 프리랜서(이름표에서 뽑은 이름 + 특기 하나, 주마다 구인 목록이 바뀐다 — 다키스트 던전의 역마차). 뼈대는 프리랜서 한 명으로 먼저 돌린다.
```ts
interface Staff {
  id: number;
  origin: 'story' | 'hire' | 'borrowed';
  name: string;            // 식구는 nameKey, 프리랜서는 이름표 조합
  grade: 1 | 2 | 3 | 4;    // 급수: 주급과 힘의 상한
  power: number;           // 힘 (의뢰 난이도와 같은 단위)
  knack: ObjectiveKind | null; // 특기: 그 목표에서 힘 ×1.3
  trauma: number;          // 0~6, 4부터 배정 불가
  gear: number | null;     // 장신구 한 칸 (소장 것과 같은 물건)
  away: number;            // 빌려준 직원: 돌아오는 날, 0 = 사무소에 있음
}
```
**하룻밤.** ① 아침에 의뢰판(평판 등급에 따라 4 → 8장). 의뢰서마다 난이도가 이미 있다(`offerDifficulty`). ② 소장이 갈 의뢰를 고르고, 남는 의뢰에 직원을 한 명씩 건다(직원 칩을 의뢰서에 꽂는다). 꽂으면 성공률이 바로 보인다. ③ 소장의 밤이 끝나면 직원들의 밤도 한꺼번에 판정한다. ④ 아침 보고에 직원마다 한 줄.
- 성공률 = `clamp(0.5 + (힘 × 특기배율 + 장신구 − 난이도) / 20, 0.05, 0.95)`. 주사위는 그날 씨앗 + 의뢰 번호(다시 불러와도 같은 결과).
- 성공: 수임료 전액이 사무소로, 평판도 그대로. 실패: 수임료 없음, 트라우마 +1(난이도가 힘보다 8 넘게 높으면 +2), 의뢰는 판에 남는다(마감은 흐른다).
- 직원은 영력·파편·장신구를 가져오지 않는다. 그건 소장의 밤에서만 나온다. 지역을 여는 메인 의뢰와 원정도 소장만 간다.
- 데려가기: 직원을 의뢰가 아니라 소장에게 꽂으면 그 밤 호출 스킬로 따라온다(식구만, [동료](../3-growth/party.md)). 그 직원은 그 밤 다른 의뢰를 못 덮는다.

**돈.** 7일마다 월세 + 주급. 주급 = 급수 × 120(1급 120 ~ 4급 480). 지금 수임료 수준(단타 150~300)에서 1급은 일주일에 두세 건 성공해야 본전이다 — 놀리면 손해, 무리하게 굴리면 트라우마. 주급을 못 주면 그 주 프리랜서는 떠나고 식구는 남되 다음 주 힘 −20%.
- 구인: 경리 장부에 "구인" 쪽. 매주 후보 3명(급수는 평판 등급까지), 계약금 = 주급 한 번. 인원 상한 = 평판 등급 + 1(식구 포함).
- 휴식: 쉬게 하면(그 밤 배정 안 함) 트라우마 −1, 소파 시설 단계만큼 동시에 −2. 자본 치료는 소장과 같은 값.
- 훈련: 직원 힘 +1에 `60 × (지금 힘 − 급수 기본값 + 1)`원, 급수마다 상한(기본값 + 6). 소장의 트레이닝과 같은 지갑이라 "나를 키울까, 직원을 키울까"가 생긴다.

**대여 (뼈대 다음, 사용자 확정 2026-11-11).** 경쟁 사무소를 시스템으로 만들지 않는다(사용자 의문: 게임 안에서 어떻게 보이나, 넣는 게 맞나). 보이지 않는 곳에서 도는 상대는 오염과 같은 문제(안 보이는 숫자)를 다시 만들고, 인물·대사가 필요해 이야기 부담만 는다. 대여는 **인력 시장** 하나로 한다. 새 화면 없이 이미 있는 두 자리에 붙는다.
- 빌려 오기 = 의뢰판 아래 "오늘 밤 배정" 줄 끝의 `＋ 빌리기` 칩. 누르면 오늘 나온 외부 인력 3명(이름, 소속, 급수, 특기, 하룻밤 값). 고르면 소속 도장이 찍힌 칩으로 배정 줄에 들어오고 내일 아침 사라진다. 값은 선불(주급의 일할 × 1.5) + 성공하면 수임료의 20%.
- 빌려주기 = 경리 장부 명단에서 직원 줄의 "내보내기"(1~3밤). 그날 시세가 보이고, 보내면 칩이 "출장 D-n"으로 흐려진다. 돌아오는 아침 보고에 한 줄: 수수료, 그리고 힘 +1이나 소문 하나(내일 의뢰판 미리보기) 중 하나. 20% 확률로 트라우마 +1.
- 다른 사무소는 목록의 "소속" 글자로만 있다(이름표 한 장, `staff.data.ts`). 의뢰를 뺏어 가지도, 직원을 빼 가지도 않는다. 놓친 의뢰의 대가는 지금처럼 마감과 평판뿐이다.
- 계산은 `(시작한 날, 끝나는 날, 상태)`의 순수 함수. 나중에 목록의 줄이 다른 플레이어의 직원으로 바뀌어도 화면과 규칙은 그대로다. 인력 시장이 재미있다고 확인된 뒤에야 소속을 얼굴 있는 사무소로 키운다.

**화면.** 의뢰판 아래 "오늘 밤 배정" 줄(직원 칩, 방향키로 고르고 F로 의뢰서에 꽂기/빼기, 성공률 표시). 경리 장부에 명단 쪽(급수·힘·특기·트라우마·주급, 훈련·휴식·구인). 아침 보고에 직원별 결과.

**저장 v8.** `staff: Staff[]`, `assign: Record<offerId, staffId>`, `escort: staffId | null`, `nextStaffId`, `hirePool`(그 주 후보), 나중에 `lends`.

**지어진 모습 (2026-11-11).** 위와 다른 점: 성공률은 난이도(1~5) × 4를 힘과 같은 단위로 쓴다(0.5 + (힘 − 난이도×4 + 4) × 0.06). 주급은 급수 × 200(120은 직원 수입에 비해 너무 쌌다 — 플레이로 고칠 것). 장신구 칸·`away`는 아직 없다(대여와 함께). 식구(이야기 직원)와 데려가기는 장이 정해진 뒤. 배정은 의뢰판에서 R, 명단·훈련·구인은 경리 장부. 저장 v9.

**짓는 순서.** 1) `src/systems/staff/`(순수 함수: 성공률, 밤 판정, 주급, 휴식, 훈련) + `staff.data.ts` + 테스트(성공률이 힘에 단조 증가, 같은 씨앗 같은 결과, 트라우마 4부터 배정 불가, 주급 정산, 직원은 영력·파편을 안 가져옴). 2) 저장 v8 + 스토어 액션 + 프리랜서 한 명 고용. 3) 배정 줄·명단 쪽·아침 보고 줄. 4) 구인 목록과 인원 상한 → 대여.
