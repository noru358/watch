## 결정
- 긴장 장치는 밀린 월세와 빚(7일마다). 레세티아처럼 가벼운 압박: 돈을 벌 이유를 만들지 게임오버를 만들지 않는다(모자라면 빚).
- 재화는 둘(2026-10-28 사용자 확정): 돈과 심연 파편. 영력은 밤에 줍는 돈(정산 때 1:1, 화면에 "영력 n = ₩n"). 평판은 쓰지 않는 경험치. 재화는 늘려도 3개까지, 쓸 때만 보인다.
- 주 수입은 밤 플레이. 낮 자동 수입(파견·대여)이 밤 플레이를 넘으면 안 된다.
- 가게 직접 운영 시뮬은 넣지 않는다(UI 폭발).

## 경영 범위 (가볍게)
월세·빚·의뢰 고르기·동네 오염(✅, [의뢰판·작전 지도](contracts-map-ops.md)), 트레이닝·기술·장신구·시설·보급품·평판(✅, [성장](../3-growth/progression.md)), 무기 손질(📝), 분대 작전(📝 첫 동료 뒤), 대여(Gate 4, [로드맵](../roadmap.md)).
