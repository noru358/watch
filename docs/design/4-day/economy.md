## ✅ 결정
- 긴장 장치 = **밀린 월세 / 빚.** 허름한 사무소 컨셉과 맞고 스토리에도 엮음 (→ [contract.md](../2-night/contract.md) 스토리 의뢰).
- 일주일(게임 내)마다 월세 마감. Recettear처럼 **가벼운** 압박 — 돈을 벌 이유를 만드는 장치이지 게임오버 장치가 아님.
- 주 수입 = 밤 플레이. 낮 자동 수입(파견·대여)은 **절대 밤 플레이보다 많이 벌면 안 됨** (ARCHITECTURE §4).

| 요소 | 내용 | 시점 |

| **평판 등급** | 의뢰 완료 → 평판 포인트 → 등급 ↑ → 새 의뢰·구역 해금 (불가사의 던전 랭크) | Gate 2 |

| 사무소 업그레이드 | 옥탑방 시설 몇 개 → [성장·시설](../3-growth/progression.md) | Gate 2 (2026-10-26 사용자 결정으로 당김) |
| 파견(분대 작전) | 대원을 보내 시간 지나면 자원 (소녀전선 군수 지원) — 밤 플레이보다 적게. 2026-10-26: 지금은 "자원 캐 오는 자동 작전" 정도로 보되 크게 바뀔 수 있음. 동료를 밤에 데려갈지 작전에 보낼지의 배분 고민과 묶어 Gate 2로 당길지 검토 중 | Gate 3 (검토 중) |
| 대여 | 대원을 다른 사무소에 빌려줌 | Gate 4 |
| ❌ 가게 직접 운영 시뮬 | 넣지 않음 (UI 폭발) | — |
