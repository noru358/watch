# 🤝 동료와 강화 카드 — 영입, 동행 슬롯, 카드 덱

← [3 성장](README.md) · 카드 숫자와 효과 목록은 [한 판 규칙](../../rules/night.md) "강화 카드". ✅ 강화 카드(기본 덱 + 무기 덱)는 들어감, 📝 동료·영입·동행 슬롯은 첫 동료와 영입 방식이 정해진 뒤(2026-10-29 recruit.md를 합침).

> **용어 (2026-10-24):** 방 클리어마다 고르는 한 판용 강화 = **강화 카드**. "기질"은 동료의 영구 성격·트라우마용으로만 씀 (Gate 2+). 코드 이름은 `CardId` / `cards.data.ts` / `registry/cardEffects.ts`.

**담당 코드:** 지금 `src/data/cards.data.ts`(카드 숫자 + `source` = 어느 덱), `src/registry/cardEffects.ts`(카드 효과), `src/systems/run/run.ts`(`cardPool` = 기본 덱 + 무기 덱에서 뽑기) / 예정 `src/data/companions.data.ts`, `src/ui/features/party/`(편성 화면)

## ✅ 결정
- **처음엔 소장 혼자.** 동료는 스토리 진행·괴이 영입(아래 "영입")으로 얻음.
- 동료가 생기면 출동 전에 **조를 편성**.
- 방식 = **동행 슬롯 + 강화 카드 덱** (축소형으로 시작)

## 게임에서 어떻게 보이나
**① 출동 전 — 조 편성 화면**
```
[소장]  [슬롯 1: 구미호]  [슬롯 2: 🔒 스토리 3장]
 무기: 신문지 사인검
 이번 판 강화 카드 덱:  기본 5장 + 사인검 5장 + 구미호 3장
```
슬롯은 스토리로 0 → 1 → 2개까지 열림.

**② 전투 중 — 호출 버튼**
데려간 동료가 호출 버튼에 들어감. 누르면 잠깐 나와서 스킬 한 방 (예시: 구미호 → 여우불로 주변 괴이 매혹. 어떤 동료가 생길지는 미정).

**③ 방 클리어 — 강화 카드 3장**
카드 테두리 색과 작은 초상화로 **어느 덱에서 나온 카드인지** 표시.
- 회색 = 기본 덱 / 파랑 = 무기 덱 / 주황 = 구미호 덱
- 동료 카드는 그 동료의 호출 스킬을 강화하거나, 무기와 섞이는 효과
  - 예: 〈여우불 부적〉 타카 딱지가 점화될 때 매혹 부여

→ **누구를 데려가느냐 = 이번 판에 어떤 카드가 나오느냐 = 이번 판의 빌드.**

## 🧑‍⚖️ 살릴 가치가 있나? → 살린다. 단, 작게.
| | 동행만 (호출 스킬) | 동행 + 강화 카드 덱 |
|---|---|---|
| 편성 고민 | 약함 — 제일 센 동료만 데려감 | 강함 — 데려간 동료가 빌드 방향을 바꿈 |
| 영입의 보람 | 스킬 하나 늘어남 | 새 빌드 길이 하나 열림 |
| 매 판 다름 | 무기·강화 카드 랜덤뿐 | 조합 × 랜덤 |
| 추가 비용 | 동료당 스킬 1개 | 동료당 스킬 1개 + 강화 카드 3장 (그림 없음, 숫자·글만) |
| 코드 비용 | — | 강화 카드 표에 "출처" 칸 하나 + 후보 뽑을 때 필터 한 줄 |

- 강화 카드는 그림이 필요 없는 **글 + 숫자 + 효과 블록**이라 1인 개발에 싸고, 콘텐츠가 늘수록 효과가 커짐 (Hades 축복 구조로 검증된 방식).
- 무기 A·B도 같은 구조로 **무기 덱**을 가짐 → "무기 덱 + 동료 덱" 하나의 규칙으로 통일.

### 도입 순서
| 시점 | 내용 |
|------|------|
| ✅ 지금 | 소장 혼자. 기본 덱 + 사인검 덱. 동료 없음 |
| Gate 2 | 동행 슬롯 1개. 동료 2~3명, 각 호출 스킬 1 + 강화 카드 3장 |
| 이후 | 슬롯 2개, 동료 간 시너지 카드 (재미 검증되면) |

## 영입 (📝 방식 미정)
- 귀신을 꼭 퇴치만 하는 게 아니라 **성불/설득시키면 대원이 됨.** (예: 술친구가 된 구미호 → 동행 동료)
- 가챠 없이 수집의 재미를 주는 핵심 장치.

| 귀신 종류 | 영입 방식 |
|----------|----------|
| 일반 귀신 | 성불시키면 **낮은 확률**로 영입 (SeededRNG) |
| 구역 보스급 원한 귀신 | 해당 **스토리 의뢰 클리어 시 확정** 영입 |

## 영입된 대원이 하는 일
- 동행: 밤에 호출 스킬로 참전 + 자기 강화 카드 덱을 판에 섞음 (위)
- 파견(분대 작전): 소녀전선 군수작전처럼 보내 두면 자원을 캐 옴, 상한 있음. 무게와 시점은 미정 → [economy.md](../4-day/economy.md)
- 기질·트라우마 보유 (예정 — 효과는 `registry/`에 블록으로)

### 방식 고민
위 표(일반 귀신 확률 + 보스 확정)는 첫 안이고, 방식 자체를 다시 고민 중이다(→ [기획 방향](../1-foundation/direction.md)).

| | 에피소드 영입 | 확률 영입(카드·등급식) |
|---|---|---|
| 좋은 점 | 동료마다 이야기로 들어와 정이 붙는다. 은혼식 관계 서사와 잘 맞음 | 수집·반복 동기, 모바일 과금 모델(소녀전선 캐릭터 카드·등급·옵션 다변화)과 잘 맞음 |
| 비용·위험 | 동료 하나 = 에피소드 하나라 콘텐츠 비용이 큼, 동료 수가 적어짐 | 등급·옵션 밸런스 작업이 큼. 이야기가 얕아지기 쉬움 |
| 지금 규칙과 부딪히는 점 | 없음 | [과금](../5-business/monetization.md)의 "최종 능력치 직접 구매 안 함"과 가까워질 수 있음. 대여 시장 수수료가 서버 재계산이라(ARCHITECTURE 규칙 7) 옵션이 많을수록 복잡 |

섞는 안도 있다: 이야기 동료(소수, 에피소드, 확정)와 수집 동료(다수, 확률, 이야기는 짧게)를 나누는 것. 인간 퇴마사 동료를 둘지도 미정.

## 🤔 남은 것
- 영입 방식(위), 확률이면 수치·중복 처리·등급, 영입 가능한 귀신 범위.
