| | 대충 하는 봇 | 잘하는 봇 | 의미 |
|---|---|---|---|
| 액션판 | 가만히 서서 공격만: **6/8 클리어** | 피하며 공격: 8/8 | 실력이 거의 상관없음 (자동 조준이 다 해 줌) |

여기에 제작 부담(그림·판정·동료 AI), 모바일 조작, 동료 편성과의 궁합까지 칸 턴제가 유리.

## 조작 (버튼 4개 — 모바일 기준 충족)
| 키 | 행동 |
|----|------|
| WASD | 한 칸 이동 · 괴이에게 부딪히면 베기. 누르고 있으면 연속 이동 |
| J | 바라보는 칸 베기 |
| K / Space | 한 턴 대기 |
| L | **발도** |

## 규칙
- 내가 1번 행동 → 괴이들이 1번씩 행동.
- 붙은 괴이는 **"!" + 분홍 칸**으로 다음 턴 공격을 예고 → 비키기 / 발도 / 맞으면서 때리기.
- **발도로 막을 수 있는 건 바로 옆 괴이의 근접 공격뿐.** 지하철 망령 돌진, 보스 롤러 줄 공격은 비켜야 함.
- **무기 A 신문지 사인검**
  - 평소엔 신문지째 베기(회색 막대). 연속으로 맞히면 **3타째 강타**.
  - 맞힐 때마다 **진심 게이지** +1, 꽉 차면 아무 때나 발도 → 주변 8칸 일섬.
  - 발도 성공 시 신문지가 찢어지며 **검신 노출**(푸른 막대) → 몇 턴 동안 베기 피해 증가.
- 한 밤 = 을지로 의뢰: **일반 3층(2층에 ☎ 공중전화) → 원인 괴이의 방(윤전기 귀신)**.
- 층을 내려갈 때마다 **강화 카드 3장 중 1장** (기본 덱 + 사인검 덱).
- 보스 윤전기 귀신: 줄(행) 롤러 휩쓸기(2페이즈엔 행+열), 처녀귀신 소환, 붙으면 근접 공격(발도 가능). 체력 절반에서 네온 2페이즈.
