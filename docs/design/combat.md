# ⚔️ 밤 전투 방식 모듈 — 🤔 결정 대기 (두 시험판 비교 중)

**담당 코드:** 액션판 `src/systems/combat/` + `src/scenes/rift/` / 칸 턴제판 `src/systems/grid/` + `src/scenes/grid/`
**공용 (어느 쪽이 이기든 그대로 씀):** 의뢰 `systems/contract/`, 정산 `systems/run/`, 금고 `store/`, 연출 `scenes/shared/`

## 왜 두 개인가
실시간 액션은 손맛이 좋지만 제작 부담(동작 그림, 판정 조정, 동료 AI, 모바일 조작)이 큼.
칸 턴제(불가사의 던전식)는 부담이 작고 동료·모바일에 유리하지만 손맛이 약할 수 있음.
→ **직접 해 보고 고른다.** 비교표는 [playflow.md](playflow.md)·[불가사의 던전 역설계](../reference/pokemon-mystery-dungeon.md)

## A. 액션판 (사무소 화면 청록 버튼)
| 키 | 행동 |
|----|------|
| WASD | 이동 |
| J (누르고 있기) | 부적 던지기, 가까운 괴이 자동 조준 (= 무기 B 타카의 초안) |
| K / Space | 구르기 (무적) |
| L | 부적 결계 |
| ; | 동료 호출 (임시 동료 3명 — 삭제 예정) |

방 7개: 전투 3 → ☎️ 공중전화 → 전투 2 → 👹 윤전기 귀신(탄막 → 조준 연사 → 소환, 절반에서 네온 2페이즈). 방마다 강화 카드 3택.

## B. 칸 턴제판 (사무소 화면 노란 버튼)
| 키 | 행동 |
|----|------|
| WASD | 한 칸 이동 · 괴이에 부딪히면 공격. 누르고 있으면 연속 이동 |
| J | 바라보는 칸 베기 |
| K | 한 턴 대기 |
| L | **발도** — 바로 옆 괴이의 예고 공격을 받아치기 / 진심 게이지 꽉 차면 주변 8칸 일섬 |

- 내가 1번 움직이면 괴이도 1번. 붙은 괴이는 **"!" + 분홍 칸**으로 다음 턴 공격을 예고 → 비키기 / 발도 / 맞으면서 때리기 중 선택.
- 멀리서 오는 돌진(지하철 망령)은 발도로 못 막음 → 옆으로 비켜야 함.
- 무작위 맵 3층, 층마다 강화 카드 3택. 계단 밟으면 다음 층.

## 비교할 때 볼 것
1. 10분 했을 때 **더 하고 싶은 쪽**
2. "평소엔 대충, 진심일 때 간지"가 **발도 순간**에 느껴지는 쪽
3. 나중에 **동료 2~3명**이 같이 싸우는 모습이 그려지는 쪽
4. 폰으로도 할 수 있겠다 싶은 쪽

- 진 쪽 코드는 지우거나 보관 브랜치로. 이긴 쪽에 **무기 A 사인검(신문지 + 발도)** 적용, 임시 동료 삭제, 강화 카드를 기본 덱 + 무기 덱으로 분리.
