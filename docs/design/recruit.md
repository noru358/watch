# 👻 귀신 영입 모듈

**담당 코드:** `src/data/recruit.data.ts`(확률·조건), `src/systems/recruit/`(영입 판정)

## ✅ 결정
- 귀신을 꼭 퇴치만 하는 게 아니라 **성불/설득시키면 대원이 됨.** (예: 원한을 푼 처녀귀신 → 사무소 경리)
- 가챠 없이 수집의 재미를 주는 핵심 장치.

| 귀신 종류 | 영입 방식 |
|----------|----------|
| 일반 귀신 | 성불시키면 **낮은 확률**로 영입 (SeededRNG) |
| 구역 보스급 원한 귀신 | 해당 **스토리 의뢰 클리어 시 확정** 영입 |

## 영입된 대원이 하는 일
- 동행: 밤에 호출 스킬로 참전 (→ [protagonist.md](protagonist.md))
- 파견: 정화된 구역에 자동 파견, 보조 수입 (Gate 3, 상한 있음)
- 기질·트라우마 보유 (기존 `registry/traitHooks.ts`)

## 🤔 남은 것
- 확률 수치, 중복 영입 처리(같은 귀신 2번?), 영입 가능한 일반 귀신 범위.
