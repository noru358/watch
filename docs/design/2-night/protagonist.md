# 🧥 주인공·퇴마 도구 모듈

**담당 코드:** `src/data/weapons.data.ts`(무기 숫자), `src/data/protagonist.data.ts`(체력 등), `src/systems/rift/player.ts`(베기·발도·돌진 규칙), `src/systems/run/stats.ts`(능력치 계산)

## ✅ 결정
- **사무소장 1명 고정.** 허름한 을지로 사무소, 귀찮아하지만 수임·의뢰 해결엔 천부적인 해결사.
  - 결: 은혼 해결사, 레이겐(모브사이코), 스파이크(카우보이 비밥) 계열.
- **투잡 (2026-10-25 결정):** 낮에는 중소기업 직장인, 퇴근 후 밤에는 부업으로 퇴마 사무소장. 그래서 퇴마는 밤에만 하고 늘 피곤하다. 낮 동안 사무소는 경리와 뚱고양이가 지킨다.

## ✅ 외형 (2026-10-25 사용자 사양 + 도트용 정리)
20대 후반~30대 초반. 만성 피로와 무던함이 밴 쿨한 직장인, 과장 없이 일을 건조하고 깔끔하게 처리하는 한량형 천재. 성별은 아직 미정(지금 사양은 중성적으로 읽힘).

| 부위 | 사양 |
|------|------|
| 머리 | 중단발 레이어드 컷. 쇄골 라인에서 안팎으로 가볍게 뻗침, 이마·광대를 따라 떨어지는 시스루 뱅과 사이드뱅(가운데 머리는 밖으로 안 뻗침). 다크 브라운 / 내추럴 블랙 |
| 아우터 | 노카라 라운드넥 숏 자켓, 미니멀한 실루엣, 전면 실버 메탈 버튼. 색은 순검정 대신 먹색(밤 배경에 묻히지 않게) |
| 이너 | 블랙 터틀넥 니트 |
| 하의 | 연베이지 핀턱 와이드 슬랙스, 발등 위로 여유 있게 떨어지는 세미와이드. 허리 핀턱 주름 = 철릭 주름 자락의 현대식 재해석 |
| 신발 | 편한 신발(밝은 운동화) |
| 소품 | 파란 줄 목걸이형 사원증(케이스 뒤에 부적이 삐죽), 나일론 크로스백(노트북·서류)에 노리개 |
| 무기 | 신문지에 싼 사인검 — 퇴근길 회사원이 신문지 말아 든 모양 |

사원증은 다니는 회사 것이다. 1인 사무소 소장이 퇴마 사무소 사원증도 만들어 거는 개그는 나중 선택지로 남겨 둔다.

도트(키 24px)에서 반드시 남길 순서: ① 쇄골에서 뻗치는 중단발 실루엣 ② 위 먹색·아래 베이지 대비 ③ 파란 사원증 줄 + 흰 카드 ④ 크로스백 끈 대각선. 시스루 뱅·단추·핀턱은 1~2픽셀 암시로만. 상세 디테일은 대화창 초상화에서 살린다. 견본: [아트 모듈](../5-business/art.md).
- 플레이 다양성은 직업 선택이 아니라 **퇴마 도구 교체**로 (Hades 무기 교체처럼).
- 처음엔 **소장 혼자.** 동료는 나중에 얻고, 직접 조작하지 않고 **동행 → 호출 스킬**로 참여 (→ [party.md](../3-growth/party.md)).

## ✅ 퇴마 도구 (2026-10-24 결정: A + B)
| 순서 | 도구 | 평소 | 손맛 포인트 |
|------|------|------|-----------|
| **A. 시작** | 🗞️ **신문지에 둘둘 만 사인검(四寅劍)** | 불심검문 피하려고 신문지·검은 비닐에 말아 들고 다님. 잔챙이는 칼집째 퍽퍽 | 보스 공격에 맞춰 **[발도]** → 신문지가 찢어지며 푸른 벼락 검신, 화면 가로지르는 일섬 |
| **B. 해금** | 🏷️ **부적 라벨기 타카** | 붓질 귀찮아서 마트 가격표 라벨기를 개조. 괴이 이마에 *철컥!* [급급여율령 - 50% 할인가] | 딱지 5장 이상 붙으면 **[점화]** → 손가락 딱, 연쇄 폭발로 데미지 숫자 와르르 |

- 근접(A) ↔ 원거리·누적(B)로 대비. 무기마다 **무기 덱**(전용 강화 카드)을 가짐 → [party.md](../3-growth/party.md)
- C(염주 맨주먹)는 보류.
- A는 실시간으로 구현됨. B(타카: 딱지 쌓기 → 점화)는 Gate 2.
