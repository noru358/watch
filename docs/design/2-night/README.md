# 2 밤 — 퇴마 현장

밤에 의뢰 현장에 들어가 싸우고 나오는 모든 것. [전투](combat.md)가 중심이다(조작·발도·손맛과 결정 경위). [주인공·무기](protagonist.md)는 사무소장과 신문지 사인검, [괴이 도감](enemies.md)은 강적·잡몹·보스의 역할, [이야기 의뢰와 층 구조](contract.md)는 방 역할·계단과 첫 의뢰 「불 꺼지는 동네」, [의뢰 목표](objectives.md)는 섬멸 말고 구조·추격·결계·호위를 실시간에 맞게 바꾼 목표와 "목표 달성 시 귀환"(구조까지 ✅, 나머지 📝), [실패·정산](run-result.md)은 끝났을 때 무엇을 얻고 잃는지.
