# 2 밤 — 퇴마 현장 (Gate 1 본체)

밤에 의뢰 현장에 들어가 싸우고 나오는 모든 것. [전투 방식](combat.md)이 이 묶음의 중심이고(조작·규칙·조작감·결정 경위), [주인공·무기](protagonist.md)는 사무소장과 신문지 사인검, [괴이 도감](enemies.md)은 강적·잡몹·보스의 역할과 층별 출현, [의뢰·현장](contract.md)은 층 구성과 맵 생성, [실패·정산](run-result.md)은 끝났을 때 무엇을 얻고 잃는지, [의뢰 목표](objectives.md)는 섬멸 말고 구조·추격·결계·호위를 실시간 구조로 바꾼 의뢰 종류와 "목표 달성 시 귀환"(📝 기획).
