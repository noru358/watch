# ⚖️ 실패·정산

← [2 밤](README.md) · 지금 계산(전리품 몇 %, 트라우마 몇)은 [한 판 규칙](../../rules/night.md) "정산".

**담당 코드:** `src/systems/run/settle.ts`(`settleRun(result, wallet)`, 순수 함수, 테스트 `tests/run.test.ts`), 숫자 `src/data/penalties.data.ts`.

## 결정
- 끝나는 길은 셋. 성공(수임료 + 전리품), 공중전화 귀환(실패가 아님: 전리품은 지키고 수임료만 없음), 쓰러짐·의뢰 포기(전리품 일부 잃음 + 트라우마).
- 실패 벌칙을 한꺼번에 다 걸면 너무 아프고 모바일에서 "돈 내고 손실 막기"로 보이기 쉬워서 나눠 건다. 기본은 트라우마 + 이번 판 전리품 일부. 경험치 손실·보유 돈 손실은 `penalties.data.ts`에 꺼 둔 채(0) 후보로만 둔다. 장비가 생기면 플레이어가 고르는 고위험 의뢰에만 장비 손실을 거는 안이 있다.
- 목표를 끝낸 뒤 귀환을 고르면 수임료를 받는 성공으로 친다(📝 [의뢰 목표](objectives.md) "목표 달성 시 귀환").
- 트라우마의 효과와 회복은 [성장·시설·트라우마](../3-growth/progression.md).
- 과금으로 벌칙을 없애는 상품은 만들지 않는다([과금](../5-business/monetization.md)).
