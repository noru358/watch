## 결정 경위 (2026-10-25)
1. 액션판(자동 조준)과 칸 턴제판을 봇으로 비교 → 액션판은 가만히 서서 휘둘러도 6/8 클리어라 턴제로 결정.
2. 사용자가 턴제판을 해 보니 애매했고 턴제 자체가 취향이 아님 → **그리드 위 실시간**(코어키퍼식)으로 재결정.
3. 실패 원인이던 "자동 조준·예고 없음"을 고쳐서 다시 만듦: 조준은 마우스, 모든 공격은 바닥 예고, 근접만 발도로 받아칠 수 있음.

합격 기준(자동 테스트 `tests/balance.test.ts`): 가만히 서서 휘두르는 봇은 8판 중 2판 이하, 예고를 읽는 봇은 6판 이상. 지금 0/8 vs 8/8. 칸 턴제판 코드는 git `0278d77`, 옛 액션판은 `d170e4b`.

## 조작 — 기능 하나에 키 하나 + 마우스 버튼 하나
이동 WASD, 조준 마우스(안 쓰면 움직이는 방향, 멈추면 3칸 안 가장 가까운 괴이), 베기 J/좌클릭(누르고 있으면 연속), 돌진 Space, 발도 K/우클릭, 일시정지 Esc(계속하기 · 조작 안내 · 의뢰 포기 = 실패 처리), 카드·공중전화 선택 1/2/3. 전투 버튼은 4개까지(ARCHITECTURE 규칙 4): 지금 셋 + 동료 호출 자리 하나.

## 규칙
- 괴이의 공격은 전부 바닥에 먼저 표시된다. 노란 예고는 근접이라 발도로 받아칠 수 있고, 맞기 직전 테두리가 하얗게 번쩍인다. 빨간 예고(지하철 망령 돌진, 보스 꼬리 쓸기)는 받아칠 수 없어 피해야 한다. 몸이 닿아도 피해는 없고 피해는 예고로만 들어온다(잡몹 도깨비불만 닿으면 1).
- 베기: 앞 부채꼴, 3타 콤보(1타 내려베기 → 2타 되돌려 올려베기 → 3타 찌르기 마무리 + 숨 고르기, "탁, 탁, 타악 — 쉼"). 맞힐 때마다 진심 게이지 +1.
- 돌진: 짧은 이동, 앞부분만 무적(Gungeon 구르기), 재사용 대기.
- 괴이 역할(강적·잡몹·보스)은 [괴이 도감](enemies.md), 층 구성과 목표는 [이야기 의뢰·층](contract.md)·[의뢰 목표](objectives.md).

## 발도 — 키 하나, 결과 셋 (2026-10-25 "뭐가 뭔지 모르겠다" 피드백)
언제 눌러도 반드시 뭔가 나간다. 평소엔 앞을 크게 벤다. 노란 예고가 번쩍일 때 누르면 받아치기: 그 공격이 취소되고, 상대가 잠깐 멈추고, 칼이 몇 초 드러나 베기가 세지며, 주변 원형 전체에 큰 피해. 진심 게이지가 꽉 차 있으면 같은 크기의 일섬(게이지 소모). 예전의 "헛치면 무방비" 페널티는 없앴다.

**피해 순서(테스트가 지킴):** 어떤 평타 < 일반 발도 < 받아치기 = 일섬. 범위도 받아치기·일섬이 일반 발도보다 넓다. 발도 카드(〈푸른 벼락〉)는 일반 발도와 받아치기·일섬을 함께 올려 순서가 유지된다.

**발도의 "탁":** 누르면 짧게 발도 자세(멈춰 서서 칼자루에 손, 칼날 근처 반짝임, 코등이 미는 '틱' 소리) → 베기와 큰 멈춤 + 흰 일직선 섬광 + 범위 호/원 → 납도. 받아치기 판정은 누르는 순간 하므로 반응은 그대로이고 피해만 자세 뒤에 들어간다(고스트 오브 쓰시마 대치처럼 "긴장 → 한 번에 베기"). 자세 동안 못 움직여서 일반 발도에는 약간의 위험이 있다.

범위를 눈으로 알 수 있게 발도를 쓸 때마다 범위가 호(앞 베기)나 원(받아치기·일섬)으로 번쩍이고, 게이지가 차 있으면 주인공 둘레에 일섬 범위 원이 깔린다. HUD 발도 칸은 지금 누르면 무엇이 나가는지 보여 준다([화면·UI](../1-foundation/ui.md)).

## 손맛·연출 결정 (2026-10-25 피드백)
- "맞을 때 너무 흔들리고 정신없다": 흔들림은 약하게(피격 흔들림·멈칫은 특히 작게), 화면 전체 번쩍임 대신 가장자리의 옅은 빨간 테두리, 보스 2페이즈·받아치기의 큰 번쩍임은 없앰. 데미지 숫자는 작게(잡몹은 더 작게). 수치는 `feel.data.ts`.
- "위아래 공격이 어색": 몸 그림은 좌우 2방향(반전), 방향은 칼과 휘두름 잔상이 조준 쪽으로 돌아가며 보여 준다(소울나이트식). 위쪽(약 30° 이상)으로 칠 때만 뒷모습 공격 프레임을 쓰고 칼·잔상을 몸 뒤에 그린다(Enter the Gungeon의 앞/뒤 전환). 아래쪽은 3/4 앞모습 그대로.
- "평타가 휙휙휙": 3타가 각기 다른 자세·궤적(앞으로 뻗은 팔 + 위→아래 초승달, 치켜든 팔 + 아래→위, 낮게 파고들며 곧은 찌르기), 각 타 뒤 회수 자세. 잔상은 앞이 두껍고 꼬리가 가는 초승달로 순식간에 호를 긋고 천천히 사라진다. 프레임 번호는 `sprites.data.ts`.

## 화면
타일 맵 위 3/4 탑뷰(벽은 윗면을 올리고 앞면을 그림), 몸은 그림자 + 발밑 y정렬, 카메라 추적. 칸 크기·배율·그림 상태는 [아트](../5-business/art.md). 괴이는 둥둥 떠다니기 + 투명도 일렁임 + 맞으면 흰색 번쩍. HUD는 [화면·UI](../1-foundation/ui.md).
