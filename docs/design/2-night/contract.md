# ☎️ 의뢰·밤 한 판 모듈

**담당 코드:** `src/data/contracts.data.ts`(의뢰별 층 구성·수임료), `src/data/dungeon.data.ts`(맵 생성), `src/systems/rift/mapgen.ts`(무작위 층 생성)

## ✅ 결정
- **의뢰 1건 = 밤 1판 = 10~15분.**
- 흐름: 의뢰 접수 → 현장 도착 → **무작위 층 여러 개** 탐색·전투 → 원인 괴이(보스) 해결 → 정산(→ [run-result.md](run-result.md))
- 의뢰 종류 두 가지 섞기:
  - **스토리 의뢰** — 직접 쓴 이야기. 순서 고정, 보스급 귀신 영입 연결(→ [recruit.md](../3-growth/recruit.md)), 월세·빚 이야기와 엮임(→ [economy.md](../4-day/economy.md))
  - **일반 의뢰** — 자동 생성. 현장·귀신 조합·보상을 데이터 표에서 뽑음 (SeededRNG 사용)
- 현장 예시: 을지로 노포 지하, 폐모텔, 막차 끊긴 지하철역.
- 현장 맵은 **무작위 생성**: 방 여러 개 + 복도. 구역마다 타일셋 1개만 바꿈 (→ [art.md](../5-business/art.md))

## ✅ 첫 의뢰 이야기: 「불 꺼지는 동네」 (2026-10-25)
원칙: 그래픽적 매력이 먼저, 이야기는 그 다음. 특정 실제 장소·업종에 묶지 않는다.

**보스: 구미호 「월하(月下)」.** 하얀 여우, 부채처럼 펼쳐진 꼬리 아홉 개, 꼬리 끝마다 푸른 여우불. 2페이즈에는 꼬리 불이 분홍 네온으로 바뀐다. 작은 픽셀에서도 실루엣(꼬리 부채)만으로 한눈에 보스로 읽히는 것이 핵심.

**패턴(코드와 대응):** 꼬리 쓸기(빨간 띠, 피해야 함) = 꼬리 아홉 개가 방 한 줄을 통째로 쓸어감, 2페이즈는 가로+세로. 덮치기(노란 원, 받아치기 가능) = 가까우면 뛰어올라 덮침. 여우불 흩뿌리기 = 도깨비불 세 개 소환. 체력 절반에서 2페이즈(빨라짐).

**이야기(짧게):** 밤마다 한 동네의 가로등과 간판 불이 하나씩 꺼지고, 꺼진 자리엔 푸른 불이 떠다닌다. 범인은 도시가 너무 밝아 수백 년째 잠을 못 잔 구미호. 불빛을 하나씩 꼬리 끝에 삼키며 동네를 어둡게 만드는 중이다. 쓰러뜨리면 한마디: "…그냥 좀 자고 싶었어." 만성 불면 괴이와 만성 피로 직장인의 짧은 공감(은혼 톤). 소장은 사무소에 굴러다니던 수면 안대를 건네준다. 나중에 영입할 수 있는 괴이 후보(→ [괴이 영입](../3-growth/recruit.md)).

**층:** 불 꺼진 골목 → 지하상가(☎ 공중전화) → 옥상 → 불이 전부 꺼진 공터(보스). 지금 타일은 공용 임시 타일.
