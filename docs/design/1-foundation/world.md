## ✅ 결정
- **자유로운 마경 서울.** 혈계전선·은혼의 에도처럼 무엇이 튀어나와도 이상하지 않은 가상의 서울.
  - 괴이를 매번 "현대인의 피로" 같은 사회 설정에 묶지 않음.
  - 전통 요괴·도깨비·이무기·구미호부터 서구권 크리처까지 출몰 가능. 비중은 **한국 요괴 7 : 서구 3** 정도.
  - 예: "어젯밤엔 연남동 골목에서 구미호랑 술 마셨고, 오늘은 을지로 지하에서 천년 묵은 지네 요괴를 썬다."

## 🛑 무조건 지키는 톤 (자유로운 세계관이라도 여기서 벗어나면 안 됨)
| 기준 | 내용 |
|------|------|
| 장소 | **진짜 서울의 생활감.** 을지로 인쇄골목, 노포, 옥탑방, 편의점, 막차, 공중전화, 비 오는 골목 |
| 분위기 | **서울 바이브(K-애스테틱) + 시티팝.** 노을·네온·비 반사·80~90년대 간판 색감 |
| 주인공 | **허름한 사무소의 귀차니스트 천재 해결사.** 평소엔 대충, 진심일 때만 간지. 낮엔 중소기업 직장인, 밤엔 부업으로 사무소장(투잡) |
| 웃음 | 은혼식 만담과 생활 개그. 공포는 양념, 주재료는 "쿨함 + 생활감" |
| 압박 | 밀린 월세·빚 ([economy.md](../4-day/economy.md)) |
