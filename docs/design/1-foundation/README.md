# 1 기준

모든 세부 모듈이 따르는 약속. 문서 하나에 주제 하나, 같은 내용을 두 문서에 쓰지 않는다.

- [기획 방향](direction.md): 정해진 것과 열린 것의 한 줄 목록(내용은 링크한 원본에).
- [이야기 바이블](bible.md): 세계관·톤·인물·장소·이야기 진행·쓰는 법·같이 정할 질문. 이야기·대사 작업의 입구.
- [화면·UI](ui.md): 지금 화면이 어떻게 생겼는지(의뢰판, 아침 보고, 밤 HUD, 대화창, 타이틀)와 공통 톤.
- [플랫폼·입력](platform.md): 스팀 먼저·모바일 나중, 버튼 4개 이하.
- [저장](save.md): 무엇을 언제 저장하고 버전이 바뀌면 어떻게 옮기는지.
