**담당 코드:** `src/core/InputManager.ts`, `src/core/platform.ts`(예정)

## ✅ 결정
- **스팀(PC) 먼저 → 모바일.** 같은 코드(Phaser + TypeScript)를 PC는 Electron, 모바일은 Capacitor로 감쌈.
- 시점: 비스듬한 탑다운 픽셀아트, 한 화면 ≈ 광장 하나.
- 한 판 길이는 미정(10~15분 vs 5분 안팎, [기획 방향](direction.md)). 모바일을 생각하면 짧은 쪽이 유리하고, 의뢰 목표마다 길이를 다르게 하는 안이 있다([의뢰 목표](../2-night/objectives.md) "목표 달성 시 귀환").

## 모바일을 위해 지금부터 지킬 것
| 항목 | 규칙 |
|------|------|
| 전투 버튼 | **4개 이하** — 지금: 이동 · 베기 · 돌진 · 발도 (+ PC는 마우스 조준). 모바일은 가상 스틱 + 버튼 3개, 조준 보정 |
| 화면 비율 | PC 16:9 / 폰 19.5:9 → 중요한 UI는 가운데 **안전 구역**에만 |
| 입력 | InputManager에 `touch` 입력(가상 스틱, 탭 이동) 자리 마련. 키보드·패드·터치 모두 같은 "행동"(이동/공격/회피…)으로 번역 |
| UI 표시 | 같은 기능을 PC는 단축키 글자, 모바일은 큰 아이콘으로 |

## 🤔 남은 것
- 모바일 빌드는 `ARCHITECTURE.md` §6에서 아직 범위 밖. 터치 입력은 스팀 출시 뒤.
