지금 화면이 어떻게 생겼는지만 적는다. 바꾸면 이 문서를 고치고, 언제 왜 바꿨는지는 history에 남긴다. 사무소 허브의 원칙(상시 메뉴 줄·재화 바 없음, 걸어가서 E)은 [허브](../4-day/hub.md).

## 공통 톤 (2026-10-28 사용자 결정)
- **네온은 켜진 것에만, 정보는 종이에.** 밤 책상 같은 어두운 바탕 위에 의뢰서·지도·전표·보고서를 종이로 올린다. 네온(청록 `#41e0c8`, 분홍 `#ff3cac`)은 지금 고른 것, 버튼, 긴급처럼 "켜진" 것에만.
- **글꼴 셋:** 블랙 한 산스(간판·도장·장 제목), IBM 플렉스 산스 KR(화면 글과 숫자, 숫자는 자릿수 맞춤), 나눔명조(사연·대사·장 부제). 📝 아직 게임에 안 넣음(파일로 내장해야 함).
- **도장:** 모양이 뜻 — 사각 = 시간(마감 D-n, 긴급 D-n), 원 = 상태(담음, 해결), 긴 타원 = 신분(메인 스토리, 현상수배). 잉크만 찍히고 바탕 없음. 실패 도장은 없다.
- 팔레트는 `src/data/feel.data.ts` `PALETTE`, 의뢰판 색은 `src/ui/features/board/look.ts`. 화면 960×540 기준.
- "오염", "위험" 같은 말은 화면에 쓰지 않는다. 색과 칸으로 보여 준다.

## 의뢰판 (현관문)
- 왼쪽 위 **을지로 작전 지도**: 옛 인쇄 지도 종이(가안). 동네 = 남색 테두리 블록, 오염은 블록 색(종이색 → 짙은 빨강)과 이름 아래 큐브 5칸. 고른 동네는 청록 형광 원, 긴급 동네는 분홍 점선 테두리 + 번질 이웃으로 분홍 점선 화살표. 압정 = 의뢰(색: 일반·표적·메인·긴급). 의뢰 없는 동네는 흐리게(못 누름), 평판이 모자라면 "평판 n등급부터". 지금 장은 사진 카드(사건 파일) + 단서 동네로 붉은 실.
- 왼쪽 아래 **출동 전표**: 오늘 밤 층 순서(목표 층, 지나가는 층, 깊은 층), 종합 난이도, 보수 합.
- 오른쪽 **의뢰서**(클립보드): 의뢰인, 사연 두 줄, 표적 이름, 그리고 같은 크기 칸 여섯 — 목표, 난이도(점 + 말: 가벼움 ~ 목숨 걸기), 길이, 보수(+파편), 변형, 괴이. 오염이 보탠 몫은 동네 색 표시로(점·보수·층마다 괴이). 마감 도장, 합동 출동에 담으면 "담음" 도장. 사건 파일 동네면 "사건 파일과 연결됨".
- 아래: ‹ A · 출동(Enter, 네온 테두리, 담을 수 있으면 "F 담기/빼기") · D ›. A/D 동네, W/S 같은 동네 의뢰, F 합동 출동.
- 숫자와 계산식은 [낮 규칙](../../rules/office.md).

## 아침 보고 (가안)
밤 다음 아침 사무소에 들어오면 한 번 저절로 뜨는 경리의 종이 한 장: 어젯밤 의뢰마다 한 줄(끝낸 것엔 작은 "해결" 도장, 못 끝낸 것은 "보수 없음"), 받은 것(영력 → 돈, 파편, 장신구, 평판, 단서), 오늘(월세, 오염 변화, 만료, 새 의뢰·긴급), 잔고. Enter = 의뢰판으로. 장부에서 다시 보기. 📝 저장 안 됨(껐다 켜면 그날 보고는 사라짐).

## 밤 HUD
- 위 가운데: 목표 한 줄 + 게이지(있을 때). 목표 종류는 [의뢰 목표](../2-night/objectives.md).
- 오른쪽 위: 층수 "2F / 4" + 층 막대 + "영력 n = ₩n".
- 왼쪽 아래: 체력 칸과 진심 게이지 5칸.
- 오른쪽 아래: 버튼 넷 — 베기 J, 돌진 Space, 발도 K(지금 나갈 것: 베기 / 받아치기 / 일섬), 액티브 기술 L. 동료 호출 자리는 동료를 만들 때 다시 정한다.
- 조작 안내는 일시정지(Esc)에만. 화면 가장자리 화살표는 목표·기술이 쓸 때만.

## 대화창
- 이야기 장면: 화면 아래 상자 + 초상화(소장 왼쪽, 상대 오른쪽), 이름표, 한두 줄. Enter·J·클릭 다음, Esc 장면 건너뛰기.
- 사무소 잡담: 머리 위 말풍선, 3초 뒤 사라짐, 걷기를 막지 않음, 같은 잡담 반복 금지.
- 문자: 화면 위 휴대폰 알림(집주인, 평판 등급).

## 타이틀
벽돌 벽 + 네온 간판 로고 + 가운데 세로 메뉴(이어하기 — n일째 · 잔고 / 새로 시작 / 설정). 새로 시작은 저장이 있으면 덮어쓰기 확인. 설정은 지금 음량 하나(게임 저장과 따로 저장). 화면·조작 설정은 스팀판에서.
