# 🧭 기획 방향 — 무엇이 정해졌고 무엇이 열려 있나 (2026-10-26)

← [1 기준](README.md) · 2026-10-26 기획 재검토의 결과. 다른 AI와 나눈 기획 정리를 참고로 받아, 지금 게임과 비교해 정리했다. **그 정리는 참고일 뿐 사용자의 확정 의견이 아니다.** 새 결정이 나면 이 문서부터 고친다.

## 이 게임은 (한 줄)
낮엔 중소기업 직장인, 밤엔 부업으로 을지로 옥탑방 퇴마 사무소장인 귀차니스트 해결사가 의뢰를 받아 밤에 괴이를 베고, 동료를 모으고, 월세를 막으며 사무소를 키우는 게임. 하데스형 탑다운 액션 로그라이트에 가벼운 사무소 경영과 캐릭터 수집을 얹는다.

## ✅ 확정 (바뀔 수는 있지만 지금은 이걸 기준으로 만든다)
- 세계·톤: 서울 생활감 + 시티팝, 은혼식 만담, 공포는 양념 → [world.md](world.md). 거점과 톤은 서울에 둔다.
- 주인공: 투잡 귀차니스트 소장, 신문지 사인검, 월세 압박 → [protagonist.md](../2-night/protagonist.md)
- 밤 전투: 코어키퍼식 실시간 탑다운, 모든 공격은 바닥 예고, 발도(받아치기·일섬), 3타 콤보 → [combat.md](../2-night/combat.md)
- 큰 고리: 의뢰 → 출동 → 정산 → 사무소 → 다음 의뢰.
- 사무소는 걸어다니는 실내 허브 → [hub.md](../4-day/hub.md)
- 1인 개발 범위 관리: 게이트마다 재미부터 확인하고 넓힌다 → [로드맵](../roadmap.md)

## 🤔 열려 있음 (사용자 생각 + 정할 때 볼 점)
**큰 이야기와 엔딩** — 사용자와 같이 고민한다. 틀 후보와 지금 있는 조각은 [story.md](story.md).

**분대 작전(파견)의 무게** — 사용자: 지금은 소녀전선 군수작전처럼 "보내 두면 자원을 캐 오는" 자동 작전 정도, 크게 바뀔 수 있음. 정할 때 볼 점: 동료를 밤에 데려갈지 작전에 보낼지 고르는 **배분 고민**이 생기면 낮이 대기실에서 벗어난다(아래 분대 작전과 한 묶음). 자동 수입이 밤 플레이 수입을 넘으면 안 된다는 원칙(ARCHITECTURE §4)은 그대로. 돈보다 재료·단서처럼 밤 출동을 돕는 결과가 어울린다. → [economy.md](../4-day/economy.md)

**첫 출정과 구미호** — 사용자: 첫 출정은 튜토리얼처럼 "센 괴이 하나 퇴치"로 할까 고민 중. 구미호를 동료로 데려가는 건 미정. 지금 코드의 첫 의뢰(「불 꺼지는 동네」, 보스 구미호)는 그대로 두고, 결정되면 바꾼다. → [contract.md](../2-night/contract.md)

**영입 방식과 인간 동료** — 사용자: 에피소드 영입은 이야기를 살리기 좋고, 확률 영입은 과금(소녀전선 캐릭터 카드, 등급, 성능·옵션 다변화)에 좋다. 아직 모르겠다. 정할 때 볼 점은 [recruit.md](../3-growth/recruit.md). 인간 퇴마사 동료를 둘지도 미정(1인 사무소 느낌과 부딪힘).

**그 밖** — 한 판 강화 카드 유지 여부(판 안 = 카드, 판 밖 = 동료·사무소로 나누는 안), 한 판 길이(10~15분 vs 5분 안팎), 고양이 역할, 대여 시장·무기 B의 필요성.

## 참고로 받은 제안 (다른 AI, 2026-10-26)
지금 기획에 없던 것 위주로 적는다. 채택 여부는 미정.
- 분대 자동 작전을 핵심 축으로: 조사·제압·봉쇄·구조·탐지 같은 작전 종류, 성공/부분 성공/실패, 부상·보상·후속 사건. 직접 출동과 서로 대체하지 않게: 주인공이 찾은 단서가 작전을 돕고, 작전이 모은 정보가 주인공의 탐색·보스전을 돕는다.
- 작전 지도: 을지로 안의 노드 5~8개. 의뢰판·분대 작전·나중의 서울 지도를 한 화면에.
- 액션 맵에 탐색 오브젝트·지역 기믹·단서. (비용이 커서 하더라도 "단서 줍기" 정도로 작게)
- 영입은 하나의 에피소드로, 캐릭터마다 성격·욕망·결함·관계.
- 이야기 4막 구조, 은혼식 운용(일상 의뢰는 그 자체로 재미있게, 전부 복선으로 만들지 않음).
- MVP 후보: 사무소 1, 을지로 1, 작전 노드 5~8, 액션 맵 1, 일반 적 2 + 보스 1, 퇴마사 3명 안팎, 분대 1 + 자동 판정, 메인 사건 1 + 후일담 2~3.
- 지금 기획과 다른 점(그대로 받지 않음): 한 판 강화 카드가 빠져 있고, "서울에 종속시키지 않는다"는 지금의 서울 생활감 기준과 부딪히며, 인간 퇴마사 동료는 새 요소다. 그쪽은 실시간 전투·발도·투잡 설정·게이트 구조를 모르는 상태였다.

## MVP 성공 기준 (제안, 확정 아님)
1. 직접 출동 한 판이 손맛만으로 또 하고 싶다. (Gate 1)
2. 낮에 "누구를 데려가고 누구를 보낼지, 어느 의뢰를 받을지" 고민이 실제로 생긴다. (Gate 2)
3. 의뢰 하나와 동료 하나의 이야기를 끝까지 보고 싶다. (Gate 2)

## 우선순위 (제안, 확정 아님)
전투 손맛 판정(지금) → 의뢰 지도와 하루·월세 고리 → 분대 작전 최소판(배분 고민) + 첫 동료 → 대화창과 1막 틀 → 콘텐츠 늘리기. 트라우마·평판·무기 B는 그 뒤, 대여 시장은 위 고리가 재미있다고 확인된 다음에 다시 판단.
