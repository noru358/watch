# 🧭 기획 방향 — 무엇이 정해졌고 무엇이 열려 있나

← [1 기준](README.md) · 결정마다 한 줄 요약과 그 결정의 원본 문서 링크만 둔다(내용은 링크한 문서 하나에만). 새 결정이 나면 원본 문서를 고치고 여기 한 줄을 맞춘다. 할 일 순서는 [로드맵](../roadmap.md), 결정이 나온 경위는 [작업 기록](../../history.md).

## 이 게임은 (한 줄)
밤을 무대로 움직이는 을지로 옥탑방 퇴마 사무소장, 귀차니스트 해결사가 의뢰를 받아 밤에 괴이를 베고 월세를 막으며 사무소를 키우는 게임. 코어키퍼식 실시간 탑다운 액션과 사무소 경영이 한 몸인 게임: 소장은 하룻밤에 의뢰 하나를 직접 뛰고, 나머지 의뢰는 소속 퇴마사를 배정해 덮는다.

## 2026-11-10 방향 (사용자 확정 — 아래 옛 항목과 다르면 이쪽이 우선)
- 플레이 판정: 밤 전투는 재미있고 한 판 더 하고 싶다. 문제는 한 바퀴 돌면 볼 것이 끝난다는 것.
- 경영 요소를 얹은 액션이 아니라 경영 게임이다. 소속 퇴마사 명단, 매일 밤 다 못 덮는 의뢰판과 배정, 급여, 직원 트라우마·휴식·훈련, 장신구 나눠 주기, 사무소끼리 대여. 동료 = 직원 = 이야기 인물 = 빌려주는 단위. 구조는 [경제·경영](../4-day/economy.md).
- 옛 결정은 강하게 고려할 것이지 절대가 아니다. "경영은 가볍게", "낮 자동 수입은 밤 플레이보다 적게"는 뒤집는다. 지역 해금·보스·희귀 보상은 소장이 직접 뛴 밤에서만 나온다.
- 일하는 방식: AI가 기본값을 추천하고 사용자가 컨펌하거나 뒤집는다. 결정 대기로 일을 세워 두지 않는다.
- 메뉴 쪽(기술·트레이닝·변형) 추가는 멈춘다. 화면 안(괴이·방·긴 원정·직원)에 쓴다.
- 괴이는 역할부터 늘리고 동네 배정은 나중. 방은 글자 격자 틀. 층 수는 4층에 묶지 않는다: 단타 3~4층 → 보통 → 큰 원정, 어려울수록 보상이 가파르게. 지역은 이야기 장과 떼어 먼저 연다.
- 이야기는 "직원이 될 인물 + 얼굴 있는 적" 쌍부터 짜고 큰 줄기는 마지막 → [이야기 바이블](bible.md).
- 설계가 끝난 것과 지어진 것(2026-11-11): 괴이 특성 틀 + 도깨비는 지어졌고, 나머지 괴이·방·길이·경영 뼈대는 설계만 있다 → `HANDOFF.md`.
- 그림은 개체마다 규격을 고정하고 임시 그림으로 가다 나중에 한 번에 입힌다. 화면 모양(종이 등)은 바꿔도 된다.

- 괴이는 겉(자유 창작) × 속(역할)으로 나누고, 규칙을 바꾸는 괴이는 소수만 이미 있는 네 자리(특성·현장 변형·층 목표·설치물)에 꽂는다 → [괴이](../2-night/enemies.md). 대여는 경쟁 사무소 없이 인력 시장 하나로 → [경제·경영](../4-day/economy.md) "대여". (2026-11-11 확정)

### 추천해 두고 컨펌 기다리는 것 (확정처럼 짓지 말 것)
- 오염 삭제. 사용자 의문: 생계형 퇴마사지 지역을 관리하는 전담 기구가 아니다. 추천: 오염·넘침·번짐을 지우고, 놓친 의뢰의 대가는 평판(이미 있음)과 나중의 경쟁 사무소로. 난이도는 의뢰 등급과 길이가 맡는다. 긴급 의뢰는 오염 없이 의뢰 종류로 남긴다.
- (반려 2026-11-11) "괴이는 설화 그대로" 규칙은 사용자가 뒤집었다. 괴이는 귀신을 포함한 훨씬 넓은 개념이고 완전한 창작의 영역이다 → [이야기 바이블](bible.md) "괴이란". 지금 괴이 역할 7종의 이름(몽달귀신 등)은 전부 임시다.
- 도둑 괴이는 돈이 아니라 액티브 기술을 훔쳐 달아난다(잡으면 되찾고 그 층 동안 강화, 놓치면 그 밤 동안 없음).
- 길이 숫자: 보통 6~8층, 원정 15층 이상에 5층마다 귀환 지점과 중간 보스.

## ✅ 정해진 것 (2026-10-29까지)
- 세계·톤·인물·이야기 진행 방식 → [이야기 바이블](bible.md)
- 주인공과 무기(신문지 사인검, 발도) → [주인공](../2-night/protagonist.md), 싸우는 법 → [전투](../2-night/combat.md)
- 큰 고리: 의뢰 → 출동(밤 1판 = 하루) → 정산·아침 보고 → 사무소 → 다음 의뢰, 7일마다 월세 → [경제](../4-day/economy.md)
- 사무소는 걸어다니는 실내 허브, 상시 메뉴 줄 없음 → [허브](../4-day/hub.md)
- 의뢰: 메인 스토리(장마다 하나)와 일반 의뢰(목표 7종 중 하나 + 현장 변형 0~2), 동네 오염·긴급·넘침, 같은 동네 합동 출동, 평판 등급 → [의뢰판·작전 지도](../4-day/contracts-map-ops.md), [의뢰 목표](../2-night/objectives.md)
- 지역: 장이 넘어가면 새 지역, 규칙은 같고 재료만 바뀜, 옛 지역도 오감 → [지역](../4-day/regions.md)
- 성장: 돈 = 트레이닝·시설·보급품·장신구 강화, 심연 파편 = 기술·장신구 다시 굴리기, 평판은 쓰지 않는 경험치. 기술·장신구 특수·보급품은 효과 부품 조합 → [성장·시설·트라우마](../3-growth/progression.md), 숫자는 [성장 규칙](../../rules/growth.md)
- 화면: 네온은 켜진 것에만, 정보는 종이에, 글꼴 셋, 도장 체계 → [화면·UI](ui.md)
- 그림: 사용자는 도트를 찍지 않고 판정만 한다, 지금 수준으로 두고 나중에 → [그림 작업 절차](../5-business/art-pipeline.md)
- 숨은 규칙(공식·숫자 위치)은 [규칙 장부](../../rules/README.md)에 모듈별로(사용자: "그래야 수정하지"), 게임 숫자·글 전체는 `docs/catalog.md`
- 1인 개발 범위 관리: 관문마다 재미부터 확인하고 넓힌다 → [로드맵](../roadmap.md)
