# 🧭 기획 방향 — 무엇이 정해졌고 무엇이 열려 있나

← [1 기준](README.md) · 결정마다 한 줄 요약과 그 결정의 원본 문서 링크만 둔다(내용은 링크한 문서 하나에만). 새 결정이 나면 원본 문서를 고치고 여기 한 줄을 맞춘다. 할 일 순서는 [로드맵](../roadmap.md), 결정이 나온 경위는 [작업 기록](../../history.md).

## 이 게임은 (한 줄)
낮엔 중소기업 직장인, 밤엔 을지로 옥탑방 퇴마 사무소장인 귀차니스트 해결사가 의뢰를 받아 밤에 괴이를 베고 월세를 막으며 사무소를 키우는 게임. 코어키퍼식 실시간 탑다운 액션에 사무소 경영과 성장을 얹는다.

## ✅ 정해진 것
- 세계·톤·인물·이야기 진행 방식 → [이야기 바이블](bible.md)
- 주인공과 무기(신문지 사인검, 발도) → [주인공](../2-night/protagonist.md), 싸우는 법 → [전투](../2-night/combat.md)
- 큰 고리: 의뢰 → 출동(밤 1판 = 하루) → 정산·아침 보고 → 사무소 → 다음 의뢰, 7일마다 월세 → [경제](../4-day/economy.md)
- 사무소는 걸어다니는 실내 허브, 상시 메뉴 줄 없음 → [허브](../4-day/hub.md)
- 의뢰: 메인 스토리(장마다 하나)와 일반 의뢰(목표 7종 중 하나 + 현장 변형 0~2), 동네 오염·긴급·넘침, 같은 동네 합동 출동, 평판 등급 → [의뢰판·작전 지도](../4-day/contracts-map-ops.md), [의뢰 목표](../2-night/objectives.md)
- 지역: 장이 넘어가면 새 지역, 규칙은 같고 재료만 바뀜, 옛 지역도 오감 → [지역](../4-day/regions.md)
- 성장: 돈 = 트레이닝·시설·보급품·장신구 강화, 심연 파편 = 기술·장신구 다시 굴리기, 평판은 쓰지 않는 경험치. 기술·장신구 특수·보급품은 효과 부품 조합 → [성장·시설·트라우마](../3-growth/progression.md), 숫자는 [성장 규칙](../../rules/growth.md)
- 화면: 네온은 켜진 것에만, 정보는 종이에, 글꼴 셋, 도장 체계 → [화면·UI](ui.md)
- 그림: 사용자는 도트를 찍지 않고 판정만 한다, 지금 수준으로 두고 나중에 → [그림 작업 절차](../5-business/art-pipeline.md)
- 숨은 규칙(공식·숫자 위치)은 [규칙 장부](../../rules/README.md)에 모듈별로(사용자: "그래야 수정하지"), 게임 숫자·글 전체는 `docs/catalog.md`
- 1인 개발 범위 관리: 관문마다 재미부터 확인하고 넓힌다 → [로드맵](../roadmap.md)

## 🤔 열려 있음
- 큰 이야기·엔딩·첫 동료·영입 방식 → [이야기 바이블](bible.md) "같이 정할 질문"
- 0장 → 1장이 열리는 조건(지금 가안: 4일째 또는 평판 30) → [메인 스토리 규칙](../../rules/story.md)
- 주인공 외형: 사양은 "중단발 레이어드, 성별 미정", 게임 그림은 긴 머리라 여성으로 읽힘. 어느 쪽에 맞출지 → [주인공](../2-night/protagonist.md)
- 동료 호출 키(L은 액티브 기술이 씀), 인간 퇴마사 동료를 둘지, 분대 작전(파견)의 무게 → [의뢰판·작전 지도](../4-day/contracts-map-ops.md) "분대 작전"
- 한 판 길이 목표(사람 측정 필요), 한 판 강화 카드를 계속 둘지, 뚱고양이의 역할, 대여 시장·무기 B의 필요성
- 지도 최종 모양(지금 인쇄 지도는 가안), 수식어에 효과 붙이기(장기)
